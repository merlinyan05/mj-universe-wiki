# R14：评论现场复演 emo 文案套路

- 记录日期：2026-11-01


- 来源：[“灭霸的爸爸叫灭建国”](https://www.bilibili.com/video/BV14VHG6BEv4/)，新增评论观察。
- 核对：直接阅读评论及默认回复。
- 观察：网友发情绪化句子后，回复抓住刺、薄冰等意象起外号，再预告次日回校嘲笑；观众在评论区主动演起损友。还有人用宇宙响指意象自编伤感句。
- 可用设定：找台本素材时，可以从“原评论＋回复”读出一次完整的小冲突，而不只是收集单句段子。
- 边界：不复制网友长文案为原创台本；提炼关键词被字面化、传播和反将一军的机制。
