# R06：父亲姓名盘点、评论图片与学历谐音

- 记录日期：2026-11-01


- 来源：[一口气带你认识所有超级英雄的父亲](https://www.bilibili.com/video/BV1AGxg6KEAL/)。
- 核对：直接浏览评论，并实际查看第一条热门评论附的文字图片；图片列出十行角色与人名箭头，其中奇异博士出现两个姓名版本。抽看视频画面时，字幕还明确给出蚁人父亲为蚁大勇。
- 观察：图片中的生活姓名接龙与评论里的奇爸、奇异硕士、星穹铁道等谐音接龙并存。雷神回复区把原作父亲奥丁与雷援朝叠成一个“中文名”笑话。
- 可用设定：名单有不同命名机制，不能因同一角色出现两个名字就删掉其中一个；原作纠错本身也能成为接梗。
- 边界：评论图片只有箭头；将其理解为父亲名单依赖所处视频的主题，不能单凭无标题图片判断每一层辈分。
