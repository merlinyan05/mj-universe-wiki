# MJ 宇宙的起源与传播史

更新与核对日期：2026-11-09。这里记录作品和梗的现实传播，不是角色在故事里的身世或宇宙内时间线。

目前更适合把 MJ 宇宙理解为**多个旧梗、图像和 AI 短剧逐步汇合的社区二创集合**，而不是某个人一次性写好的统一世界观。这是对下列材料的整理判断；仍未确认中文 MJ 视频、校园线或“灭建国”称呼的唯一首创者。

## 回顾提出的阶段与尚存争议

R08 约00:42—03:23的叙述是：早期胖蜘蛛侠短片，随后与吃喝、马戏团／小丑及67餐厅等内容结合，继续吸收旧梗，扩展到复联整活和校园。可以用它理解题材如何聚合，但里面的月份、首创和传播因果尚缺逐段原投稿佐证。

R29 的热门评论提出另一条回忆顺序：胖蜘蛛侠之后还有不烧心、恐怖贵宾犬、小丑、67餐厅、功夫等内容，再扩展复联。它补充了检索方向；不能以一条评论推翻其他作者，也不能拼成已证实的精确年表。

对以下说法暂不写成史实：

- **平台集中打压导致转向校园**：回顾视频描述了下架、限流与创作转向；未取得相应平台公告或完整作品样本，不能确认规模、原因及唯一因果。
- **某工具／比赛制造了整个热潮**：片内或评论提到生成工具、活动与创作激励，只证明存在这种解释；缺官方活动材料及传播数据。
- **所有版本都来自一条视频**：中文 MJ、胖蜘蛛侠图像、灭建国父名、蚁人旧梗与校园模式是不同待考问题，不能共用一个“祖师爷”结论。
- **特效在哪天上线／下线**：回顾、聚合页给出7月底、8月初及不同下线日期；目前只确认同期新闻已记录玩法，不拼成精确运营日历。[R38](../sources/R38.md)
- **MJ 就是 Midjourney 的缩写**：本轮材料不足以支持把生成工具名解释成社区称呼的确定词源。
- **Mary Jane 与 Michelle Jones 是同一个名字**：回顾与评论存在不同表述。涉及具体电影版本时应核对角色名；不把两个缩写相同的名字混成一人，也不以此推断胖蜘蛛侠就是电影里的 MJ。[R28](../sources/R28.md)、[R34](../sources/R34.md)

## 2026-11-09补充：工具、同名赛事与虚构前传

[R64](../sources/R64.md)对照了“灵光·新帧”官方赛事、政务报道与将其联系到蚂蚁App的回顾文章。官方站主办信息与活动日期不能仅凭名称或奖励数字并入App活动；具体对应尚待官方原页，活动如何促成传播也须另证。R61的10月6—7日作品记录又早于回顾所提10月8日节点，故不写成一条已证实的起因链。

可见灵光水印能证明某片带有工具标记，不能反推所有MJ视频都由同一工具生成。[R49](../sources/R49.md)另有updream标记的片例；这里记录可见标记，不把水印自动等同于完整制作流程。

旧素材入口也已分别定位：Marvel官方宣传片的片名／频道可回查，但本轮没有完整观看原片；2017年蚁人讨论、8月聊天动画复刻均见[R69](../sources/R69.md)。旧素材存在、后来配字与校园性格形成是不同问题。

[R65](../sources/R65.md)的小白故事是作者编写的宠物身世，属于宇宙内前传。即使同作者也制作过发展史，它也不能作为现实贵宾犬梗起源或真实救援事件。

## 怎样继续补证

欢迎贡献**更早的原投稿**：链接、公开作者署名、发布时间、原发／搬运／补档说明、相关时间点，以及它比现有材料具体早在哪里。评论可作线索，附上下文并标“评论回忆”；作者自述与实际可见作品分别记录。多篇解说引用同一来源，不算多份独立证据。

新材料先入 [sources](../sources/README.md)，再更新本页；性格、关系与玩法仍维护在[人物](../characters/README.md)、[梗](../memes/README.md)和[宇宙与故事模式](../universes/README.md)，不把传播时间线当成各平行世界共用的剧情正史。
