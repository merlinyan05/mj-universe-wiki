# 伪系统与假权威答案

- 类型：校园专属片例的机制归纳；其他宇宙复用时另核权威来源、可用技术与关系。
- 人物：[灭霸](../../../characters/灭霸.md)、[钢铁侠](../../../characters/钢铁侠.md)、[贾维斯](../../../characters/贾维斯.md)、[奇异博士](../../../characters/奇异博士.md)。
- 依据：[R52](../../../sources/R52.md)、[R53](../../../sources/R53.md)，转写辅助阅读与关键帧抽查。

## 变体一：伪系统诱导

损友在后台搭建系统 → 主角以为获得独有能力／奖励 → 积分与任务反馈诱导继续行动 → 表演升级 → 大奖与预期不符 → 揭穿整蛊并承担后果。

R52中，钢铁侠、贾维斯和博士参与装置与情境，灭霸根据任务行动。“系统存在”与“系统说的是真的”分开：该片是同学造的骗局，不自动建立真实系统宇宙。

## 变体二：假权威答案

主角反复对答案 → 同伴把答案包装成学霸提供 → 短暂看来可信／骗不过 → 官方答案或缺席事实揭穿来源 → 道歉赔礼 → 主角又问下一科，习惯形成结尾回扣。

R53把隔壁超人当作答案权威，但他是骗词中的标签，不能单凭此处给超人建立已证实的学霸属性。

## 共同机制与边界

二者都借主角相信的权威安排信息差，但任务表演、考后焦虑与揭穿方式不同。归纳不等于每部作品都采用全部步骤，损友也不自动拥有无限技术。可和[整蛊与反制](../../patterns/整蛊与反制.md)互相引用，不另复制一份人物设定。
