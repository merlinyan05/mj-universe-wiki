# 公共资源争夺与能力交易

- 类型：校园专属片例；可借用于餐厅、公共设施等日常场景，另核人物身份。
- 人物：[灭霸](../../../characters/灭霸.md)、[小浣熊](../../../characters/小浣熊.md)、[奇异博士](../../../characters/奇异博士.md)及其他同学。
- 依据：[R54](../../../sources/R54.md)，投币吹风机片例的音频与关键画面。

## 如何展开

有限设施与排队规则 → 各人对使用资格、耗时和费用有不同算盘 → 身体特点或超能力影响分配 → 有人提供技术换报酬／占便宜 → 群体重新协调或反制。

R54中光头、浣熊毛量和取回硬币的法术进入同一设施的使用冲突。角色同时争同一个目标，等待者、使用者和交易者互相影响，比依次发表无关台词更能建立群体关系。

## 边界

这是对本片机制的归纳，不把特定费用、法术成本、身体笑话写成永久世界规则。使用同类设施不要求新开一个宇宙；换场景时先说明规则和谁知道规则。

## 共享手机怎样变成分配失衡

[R77](../../../sources/R77.md)前半：蜘蛛侠原持有手机→以保密、充电位置换使用权→同伴轮借→原主人反而玩不到。后半：大家都带手机→博士借用被拒→教师查机→博士以不给自己玩回扣。举报有当集动机，不固定成所有作者的性格。

[R73](../../../sources/R73.md)雪天宿舍的资源还包括战甲加热、离线电影与充电宝；火锅让同伴分工采购。角色各有资源或任务，协作才推进情节。雷神递充电宝不等于已证实神力发电。[R82](../../../sources/R82.md)游戏劳务换请客，也是人情债与使用权的变体。
