# 常规宇宙／复联整活

- 常见场景：无限手套、响指、集合、作战准备、能力反制
- 世界规则：以能力、无限手套、响指和复联行动为背景；这里是二创分类，不等于电影正史。
- 版本边界：宇宙分类可以叠加，不是官方宇宙编号；具体作者版本分别记录。

灭霸提前准备与复联反制互相升级，奇异博士出计策；评论以蚁人缺席、其他时间线、许多结局接梗。[R04](../../sources/R04.md) “告老师”“手套不要了”等校园话语也可被借用，但不因此将所有人都设成学生。
