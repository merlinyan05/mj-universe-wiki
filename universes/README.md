# 宇宙与故事模式

人物是资料的主索引：每个人物只在 [characters](../characters/README.md) 维护一份档案，宇宙页面引用人物，并说明这里的身份、关系与故事规则。不同作者的版本可以并列，不追求唯一正史。

各分支在现实平台上怎样出现、怎样互相吸收，见[起源与传播史](../docs/MJ_HISTORY.md)。带“起源／前传”标题的角色身世故事，须与现实首创考据分开；本目录的宇宙划分是资料组织方式，不代表已证实的历史先后。

## 共用设定、版本与客串

- 人物基础、亲属姓名和梗分别维护在人物、关系和梗条目；各宇宙引用，不复制多份姓名表。
- 具体模式注明典型宇宙、还可用于哪些宇宙，以及使用时哪些条件发生变化。跨宇宙借用不等于自动继承全部身份。
- 例如“灭建国是谁”也可以出现在常规宇宙；这句梗不要求说话者是学生，也不能仅凭它判断发生了穿越。
- 客串注明人物采用哪个版本、沿用哪些特点、在哪个故事出现；没有明确片例时只记作可能用法，不虚构已发生的客串。
- 校园宇宙里的教师、学生关系不自动覆盖其他宇宙；CP 版本也不自动覆盖其他作者。

## 怎样补充

新增宇宙先写规则、已知片例与差异，链接已有的人物档案；人物的新版本写回该人物档案。宇宙专属模式放在该宇宙的 `patterns/`，可共享模式放在本目录的 `patterns/`，各自只维护一份。

模板：[宇宙](../templates/宇宙模板.md) · [故事模式](../templates/故事模式模板.md)。暂缺片例的模式可以先提 Issue，不必为了填目录编造内容。
