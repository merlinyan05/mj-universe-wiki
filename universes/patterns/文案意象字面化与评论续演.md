# 文案意象字面化与评论续演

- 类型：跨宇宙共用；校园版本最容易接“明天上学”。
- 依据：[R15](../../sources/R15.md)、[R17](../../sources/R17.md)，另见 [R14](../../sources/R14.md)。本轮主要核对评论与回复，不冒充片内完整流程。

## 如何展开

真诚表达情绪 → 损友抽出一个具体名词 → 把比喻按字面解释 → 给本人换上外号 → 第三人继续接话或预告次日见面 → 当事人护面子、威胁撤回小福利。

评论中的“刺”被接成刺猬、海胆；“坚硬外壳”被接成乌龟。笑点不是随便辱骂，而是对方刚说过的话立刻成为能反复调用的称呼。[R15](../../sources/R15.md)、[R17](../../sources/R17.md)

## 人物与接话关系

[灭霸](../../characters/灭霸.md)需要真的想表达情绪，才有被熟人拆解的落差。[钢铁侠](../../characters/钢铁侠.md)和[小浣熊](../../characters/小浣熊.md)可以先交换理解，再一人起外号、一人把外号放进实际场景。不要让所有人只是复读同一句。

R15 的一条回复直接分配钢铁侠、火箭、灭霸台词，最后用辣条断供收尾；这是观众在评论中写出的版本，不是该视频已核实的对白。

若采用“这下玩大了”作预警，先明确哪位搭档发现后果、他在提醒谁；既有对象关系见[口头禅条目](../../memes/这下玩大了.md)，不把它机械塞给灭霸或任何受害者。这是写法约束，不冒充 R15 评论里已出现的句子。

## 变体与边界

评论区本身就能完成一次“发文—起哄—回嘴”，不一定非要剪成次日校园戏。能力意象也能参与伤感表达，例如响指改变宇宙却改变不了心情；不能把评论自编文案署成原作者对白。

专属校园流程另见[深夜 emo，次日被嘲笑](../校园宇宙/patterns/深夜emo次日被嘲笑.md)。
