# 超能力与神器日用品化

- 类型：跨宇宙共用。
- 典型宇宙：常规复联整活、校园、日常。
- 依据：[R16](../../sources/R16.md)、[R19](../../sources/R19.md)、[R21](../../sources/R21.md)、[R22](../../sources/R22.md)。下列证据分别来自评论与标题，未完整核对所有镜头。

## 如何展开

观众熟悉的强能力／神器出场 → 用来处理很小、很俗的现实欲望 → 使用方式或后果让神器掉价 → 别人用日常物品或社会把柄压过它。

落差来自能力的用途：拯救宇宙的工具被拖进同学冲突、吃喝与生活尴尬。

## 已见材料

| 元素 | 实际看到的内容 | 能归纳到哪一步 |
| --- | --- | --- |
| 蚁人缩小 | R19 标题明确写钻进灭霸杯子喝粥、被发现 | 潜入位置可以换成日常容器；未补写具体惩罚 |
| 贾维斯、博士能力 | R16 评论说钢铁侠终于想到贾维斯、博士终于用技能 | 校园线不必默认全员失去能力；具体使用方式仍需看片 |
| 无限手套 | R21 评论比作一次性手套 | 神器被日用品化的观众解读，不是所有作品通用的消耗次数规则 |
| 家长名单 | R22 评论认为它比无限宝石有效 | 社会把柄压过武力的喜剧权重，不是正式战力设定 |

## 创作用法与边界

先选择本集保留的能力，再明确它如何服务一个小目标，以及为什么会引来反制。人物仍查[人物档案](../../characters/README.md)，不能因题材是校园就删光能力，也不能因为有超能力就跳过信息因果。

本页的展开顺序是整理归纳；要写成某部作品的剧情梗概，仍需补原片时间点。
