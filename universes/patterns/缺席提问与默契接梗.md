# 缺席提问与默契接梗

- 类型：跨宇宙共用；亦可发生在评论区。
- 核心人物：[蚁人](../../characters/蚁人.md)。
- 依据：[R16](../../sources/R16.md)、[R18](../../sources/R18.md)、[R19](../../sources/R19.md)、[R22](../../sources/R22.md)。

## 如何展开

观众或角色点出一个熟悉人物没出现 → 一句短问唤起已有笑话 → 对方只说“老地方”或放弃解释 → 大家补全潜在后果。

R16 的 B站作者与 R18 的抖音作者都在“蚁人去哪了／蚁人呢”下回复“老地方”。这是两个页面的作者回复，足以记录省略式接梗；不能仅凭这三个字确定具体位置。

## 变体

- R19 评论把问题替换成“黄蜂女去哪了”，缺席与缩小的联想能换人。
- R22 评论问“泽塔去哪了”，回复把“手套我不要了”换成“贝利亚徽章我不要了”，表明观众会跨 IP 替换人名和标志物。它们是评论续演，不代表泽塔实际在本片出场。

## 什么时候失效

观众没有前置知识，或者本集位置会改变结果时，需要交代线索。不能把“老地方”既当默契，又当足够支撑所有新剧情的地点证明。

与[蚁人去哪了](../../memes/蚁人去哪了.md)互为入口；人物位置和单集结果不在这里统一规定。
