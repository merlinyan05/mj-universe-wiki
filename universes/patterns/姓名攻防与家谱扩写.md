# 姓名攻防与家谱扩写

- 类型：跨宇宙共用模式。
- 典型表现：[校园宇宙](../校园宇宙/README.md)中的同学爆料、起哄与家长升级。
- 可复用范围：[常规宇宙](../常规宇宙/README.md)等也能询问“灭建国是谁”；此处说明可复用性，不声称已核对了新的片例。

1. 先把家长姓名当成隐私或把柄爆出；“某某是谁”将名字再念一遍，评论也参与扮演同学。[R02](../../sources/R02.md)、[R06](../../sources/R06.md)、[R13](../../sources/R13.md)
2. 整蛊目标由被爆料者转向情报提供者，观众反查小浣熊的家庭。[R02](../../sources/R02.md)
3. 从建国、志强一代向梓涵、宇轩一代续编，也可以向弟弟、女儿与祖辈扩展。[R07](../../sources/R07.md)、[R10](../../sources/R10.md)
4. 后代与辈分的扩大制造“全家都被认出”的升级；证据不明的辈分仍需保留歧义。

同名变体按来源并列；名字出现不自动证明亲属关系。人物姓名的维护位置为[人物档案](../../characters/README.md)。

## 连锁告状与同名异辈

[R47](../../sources/R47.md)把告状从学生推到父辈、祖辈和更高权威，同样的曝名习惯在每一层重复；最终遇到没有对应父亲弱点的对象，原攻击失效。这是片例的递进，不要求所有名字梗都走完全部辈分。

[R48](../../sources/R48.md)图里灭火器为哥哥，[R49](../../sources/R49.md)片内则为爷爷，既有评论还另有关系。名字和亲属方向必须连着作者保存；完整姓名只维护在[人物档案](../../characters/README.md)，不把不同来源拼成一张唯一家谱。

同学也会借父名直接称呼孩子，角色代称不等于父子同一人。原作姓名、生父／继父、谐音家属称呼与评论起名要分开。

## 反查检查者与有方向的亲属评论

[R88](../../sources/R88.md)灭霸让同伴拖延，自己反查超人父名，再当面公开；新名字维护在[超人档案](../../characters/超人.md)，不在这里复制另一张家谱。

[R75](../../sources/R75.md)父亲／奶奶评论有明确方向，[R84](../../sources/R84.md)浮木只是父母谐音而非专名。出现一个词、一次代称与明确亲属标签分别处理。
