# 情报武器与攻防换位

- 类型：跨宇宙共用。
- 典型宇宙：校园姓名攻防；也可迁移到复联整活。
- 依据：[R02](../../sources/R02.md)、[R16](../../sources/R16.md)、[R22](../../sources/R22.md)。含评论归纳，不是全网作品统计。

## 如何展开

一方掌握对方不知道的消息 → 和搭档私下确认、预判反应 → 选择时机放出消息 → 对方以为自己只能挨嘲 → 新名单、隐藏信息或另一名知情者出现 → 原信息位暴露弱点，攻守交换。

关键是“谁知道什么、以为谁不知道”。[小浣熊](../../characters/小浣熊.md)总先知道消息，是叙事位置；要让他吃亏，可以让他误判自己是否已被反查，不能无缘无故把他写成听不懂局势。

## 片例与评论版本

- R22 评论直接称“情报位浣熊被信息差了”，并将家长名单与六颗无限宝石比较，名单成了校园里的有效武器。
- R16 评论把火箭看见家长姓名就嘲笑写成“被动技能”；R02 则有技能需要削弱的接梗。这是把行为规律游戏化，不是确证的数值技能系统。
- [灭霸](../../characters/灭霸.md)拿到新信息可以反击；[奇异博士](../../characters/奇异博士.md)在评论描述中既有举报版本，也有仗义版本。盟友关系要按单集说明。

## 升级与后果

升级来自新的知情范围或把柄，而不是无休止增加音量。后果可以是起哄者收声、名单转手或同学临时结盟；这些是机制归纳，具体哪一种已发生需回到来源核对。

“名单比宝石有用”是观众对笑点的比较，不能改写成物理战力排行。已有的[姓名攻防](姓名攻防与家谱扩写.md)继续维护名字接龙规则。

## 消息的取得、扩散与后续

[R40](../../sources/R40.md)有火箭精确定位厕所并召集围观；[R41](../../sources/R41.md)有解释灭霸被家长带走后的缺席。信息位可以提供地点、动员他人，也可以补事后结果。

[R42](../../sources/R42.md)让钢铁侠为灭霸反查浣熊；[R50](../../sources/R50.md)明确交代被屏蔽动态如何在虚构情节里取得。攻防变化仍要有消息来源，不能靠无解释的全知。
