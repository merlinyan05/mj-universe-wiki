# 灭霸与绿巨人宇宙

- 常见场景：恋爱、健身、误会、关系揭底、跨作品拼接
- 世界规则：记录以两人关系为核心的作者版本；各系列仍可能有不同进度和人物关系，不合并成同一连续剧情。
- 版本边界：宇宙分类可以叠加，不是官方宇宙编号；具体作者版本分别记录。

灭霸／浩克已有连续 CP 系列标题与合集资料。[R03](../../sources/R03.md) 健身片例也以浩克引起灭霸反应。[R11](../../sources/R11.md) 评论能续编后代，但不能把猜想升级为片内关系，更不能覆盖其他作者版本。


## 人物与共用设定

人物统一查阅[人物档案](../../characters/README.md)，这里不另建人物副本。家长姓名、口头禅等共用设定可以跨宇宙引用；身份变化与客串在人物档案中注明版本。

## 故事模式与待补充

早期材料主要支持CP系列、目击和借钱等标题线索；[R76](../../sources/R76.md)现已补疯狂渊渊第2—4集的伴侣与家庭日常、卡魔拉女儿称谓，未据此还原全部集数或统一血缘机制。详见[两人关系条目](../../relationships/灭霸与浩克.md)。欢迎补充告白、误会或关系曝光的实际片例；不凭标题补写剧情。

## 相邻整活版本

[R25](../../sources/R25.md) 的身体双关与蚁人评论属于另一条可观察线索；没有足够证据把它合并进某位作者的 CP 连载。共用角色不代表单集关系、地点和后果全部相同。
