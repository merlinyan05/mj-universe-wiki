# 67 餐厅的规则与钻空子

- 类型：从日常餐桌扩展到战场客串和游戏改编的场地规则。
- 核心场景：67 餐厅。人物和奖惩跟随对应作者及片例。
- 依据：[R27](../../../sources/R27.md) 的评论版本与 [R161](../../../sources/R161.md) 的多部原片、作者补述与模组演示。

## 评论中怎样展开

角色靠近触发者 → 一句固定口号把场景变成餐厅规则区 → 必须完成吃喝任务 → 奖惩跟是否吃完挂钩 → 参与者故意留最后一口，争取自己想要的结果。

前半段来自一条把小丑能力游戏化的评论，奖惩和故意剩一口来自另外的评论与回复；目前不能断言它们出现在同一连续片段里。

## 好笑的地方

普通餐厅突然拥有类似强制领域的规则；吃饭从消费行为变成必须完成的任务。第二层笑点是参与者并非只能逃跑，而是反向选择看起来不划算的选项，让规则制造出意料之外的收益。

口号、循环表达和规则宣告能让熟悉观众很快进入情境；具体宣告要按原片核对，不把评论长串台词整段搬进作品。

## 人物与世界线边界

[胖蜘蛛侠](../../../characters/MJ与胖蜘蛛侠.md)与[小丑](../../../characters/小丑.md)各有档案。R27 的贵宾犬重复吟唱仍是评论玩法。Inanis 原片和对岸.改编已可定位小丑与战甲灭霸进入餐桌规则区的镜头。

餐厅规则可在同一作者系列中多次变招；别的作者若使用不同奖惩，应并列记录。跨 IP 的领域比较只是接梗，不用来确定谁真正打得过谁。

## 从原片到改编的规则变化

| 作者版本 | 能直接确认的内容 |
| --- | --- |
| Inanis 原片 | 对战走到绝境后，小丑出现、结手势，胜势中的战甲灭霸突然坐在餐桌前，听到必须吃完。原片未演完两种后果。作者在评论额外说明自己说的「唯心状态」中无论吃完与否都被「陪」。 |
| 对岸.署名改编 | 小丑戴上手套，说「六七餐厅」，随后出现与原版相近的进餐指令。评论里的全员失效与各路强度排行留在评论层。 |
| Rainy_an、南Nann 职场片 | 一个在领导挑菜时出现「超高情商」的餐厅档，另一个在三人两杯酒的难题中出现「67 型」。两者各有自己的上下级与分档关系。 |
| 说谎冰 MC 模组 | 让游戏角色或怪物坐下，按封闭式、开放式及时间判定演示。计时属于模组规则。 |

片内时间点和作者回复位置见 [R161](../../../sources/R161.md)。可复用的转折是先给观众一个惯常的输赢尺度，突然从交手、分菜或人数切换到必须遵守的餐桌规则。

已有 10 月 6 日抖音稿可听到店名与吃完要求，镜头从广场切到隔间旁的小桌。次日投稿可见相同桥段的不同演法。较早投稿、片内虚构的开店前史和后来战场／职场的客串分别定位。[R169](../../../sources/R169.md)

## 循环失败、换办法与宣布赢的口径

我是天空二号五战自助是另一作者版本：目标是吃回本，每轮改进入办法、处理浩克被拉黑、增加押金和损失；火箭用拿走资源宣称获利，结尾老板找妻子接缺席笑话。机制是同目标重复失败→升级手段／代价→改口径宣布赢→旧梗回扣，不与R27强制领域评论合成统一规则。[R106](../../../sources/R106.md)

该片11月8日发布，只是本轮补看片例，不称11月15—17日新创。扫描高价食物的功能属于贾维斯，不误归火箭。
