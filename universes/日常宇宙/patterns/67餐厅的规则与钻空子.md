# 67 餐厅的规则与钻空子

- 类型：日常宇宙专属的评论玩法归纳。
- 核心场景：67 餐厅；人物使用本片对应的 MJ／胖蜘蛛侠、小丑等版本，身份尚未全部核明。
- 依据：[R27](../../../sources/R27.md) 的热门评论与回复；不是已完整核对的片内剧情梗概。

## 评论中怎样展开

角色靠近触发者 → 一句固定口号把场景变成餐厅规则区 → 必须完成吃喝任务 → 奖惩跟是否吃完挂钩 → 参与者故意留最后一口，争取自己想要的结果。

前半段来自一条把小丑能力游戏化的评论，奖惩和故意剩一口来自另外的评论与回复；目前不能断言它们出现在同一连续片段里。

## 好笑的地方

普通餐厅突然拥有类似强制领域的规则；吃饭从消费行为变成必须完成的任务。第二层笑点是参与者并非只能逃跑，而是反向选择看起来不划算的选项，让规则制造出意料之外的收益。

口号、循环表达和规则宣告能让熟悉观众很快进入情境；具体宣告要按原片核对，不把评论长串台词整段搬进作品。

## 人物与世界线边界

[人物资料](../../../characters/MJ与胖蜘蛛侠.md)继续单独维护，不在本宇宙复制人物档案。“贵宾犬重复吟唱”“小丑拉人进餐厅”目前以评论机制版本记录，不写成全 MJ 宇宙统一能力表。

餐厅规则可在同一作者系列中多次变招；别的作者若使用不同奖惩，应并列记录。跨 IP 的领域比较只是接梗，不用来确定谁真正打得过谁。
