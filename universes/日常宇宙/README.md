## 新片例中的使用方式

字面理解食物名、借漫画后共同补偿、珍爱道具用于帮助朋友，补生活欲望与具体关系；不是每个日常片都归67餐厅。[R104](../../sources/R104.md)、[R94](../../sources/R94.md)

科普雇主／应届生问答、街访口吻与纯歌舞可以借用MJ人物，未必提供连续世界线或亲属信息。未经核验的政策数字不当现实指南，歌词和双浣熊画面不直接认亲。[R109](../../sources/R109.md)
