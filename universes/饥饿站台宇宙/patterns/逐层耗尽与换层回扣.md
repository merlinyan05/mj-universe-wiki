# 逐层耗尽与换层回扣

- 类型：饥饿站台题材专属；以下为对片例的整理归纳，不是所有作品的固定模板。
- 人物及版本：[灭霸](../../../characters/灭霸.md)、[绿巨人](../../../characters/绿巨人.md)等；四位投稿者分配见[宇宙页](../README.md)，人物不复制建档。
- 依据：[R122](../../../sources/R122.md)的六个视频入口；音频辅助阅读、选帧及评论的实际范围在来源页分别注明。

## 通常如何展开

1. 先给上层完整食物与宽裕感，角色因终于排到好位置而大吃。
2. 平台下降，以同一个道具连接新一层人物；上一层的行为就是下一层的处境。
3. 消费对象逐级升级：食物 → 骨头 → 盘子，部分版本继续吃台体。每层短反应就让观众预期再下一层还能剩什么。
4. 结尾给空台、落盘、威胁，或下一轮换位置／加固结构，回扣之前的过度消费。

## 人物关系怎样产生笑点

上层享受与下层不知情并置，观众比下层更早知道资源被耗尽；角色不用每次重新解释规则。换人、换层后，前面的吃法又成为自己可能承受的后果。

不是每条都包含全部步骤。灭建国の漫威剧场18日版只有空台，不能拿灭jack版吃台体的动作补进去；恶臭大鸡柳的下一周仅是该片周期，角色猜全饿死也不当已发生事实。

## 评论续演不回填原片

继续吃墙、五千层食量、电影抄MJ等把升级推得更远，可另标评论共创。金蛇草莓塔与67餐厅只因观众联想而相连，未确认同一地点。详细版本及待核见[宇宙页](../README.md)。
