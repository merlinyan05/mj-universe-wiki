# 饥饿站台宇宙

- 分类：把下降食物平台、上下层资源差与换层安排套入MJ人物的题材分支；本页为资料分类名，不代表各投稿者共用同一世界。
- 人物沿用[灭霸](../../characters/灭霸.md)、[绿巨人](../../characters/绿巨人.md)、[小浣熊](../../characters/小浣熊.md)、[钢铁侠](../../characters/钢铁侠.md)、[美国队长](../../characters/美国队长.md)、[奇异博士](../../characters/奇异博士.md)、[小丑](../../characters/小丑.md)和[胖蜘蛛侠](../../characters/MJ与胖蜘蛛侠.md)等外形，具体行动和分层按作者单片。
- 共用母题：平台从上向下传递，上层消费挤压下层资源。不是已核统一能力禁用、固定楼层或永久死亡规则。

## 11 月 28 日复核的衍生版本

灭jack 的 15.0 版把全餐、餐具与台面本身依次耗尽，最后给第五层美队与黑寡妇一个空洞。孩子们我带你们打舟的明日方舟版让角色用 PRTS 查楼上住客和食物，以不同角色和编号再演一遍站台机制。评论中用桃金娘接蚁人缺席的问法，有可见的社区复用，具体去向仍待核。[R167](../../sources/R167.md)

卡兹sama 的《进狱暴食》原页标明番外和补档。灭霸、浩克面对堆满食物的升降台，末段在白房和空盘堆里延续进食。楼层、后果与其他改编的对应关系均按各片证据记录。[R139](../../sources/R139.md#11-月-28-日回访作者与另一条番外)

## 故事模式与共享边界

- 专属：[逐层耗尽与换层回扣](patterns/逐层耗尽与换层回扣.md)，[模式索引](patterns/README.md)。
- 可共享：[字面化与评论续演](../patterns/文案意象字面化与评论续演.md)解释评论如何继续吃平台／墙；[作者与评论外溢](../patterns/作者下场与评论外溢.md)解释倒称电影抄MJ。
