# 通常ユニバース／アベンジャーズおふざけ

- よくある場面：インフィニティ・ガントレット、指パッチン、集結、戦闘準備、能力への対抗
- 世界のルール：能力、インフィニティ・ガントレット、指パッチン、アベンジャーズの行動を背景とする。ここは二次創作の分類であり、映画の正史とは異なる。
- 版本の境界：ユニバース分類は重ね合わせることができ、公式のユニバース番号ではない。具体的な作者の版本は個別に記録する。

サノスの事前準備とアベンジャーズの反撃が互いにエスカレートし、ドクター・ストレンジが策を出す。コメントはアントマンの不在、他のタイムライン、多数の結末で返す。[R04](../../sources/R04.md)の「先生に言う」「ガントレットはいらない」といったキャンパス的な言葉も借用できるが、それによって全員を生徒に設定するわけではない。

[ユニバース索引へ戻る](../README.md)

## 人物と共用設定

人物は一括して[人物ファイル](../../characters/README.md)を参照し、ここに人物の複製を作らない。保護者の名前や口癖などの共用設定はユニバースをまたいで参照できる。身分の変化と客演は人物ファイルに版本を明記する。

## ストーリーパターンとユニバース間の借用

能力への対抗とアントマン不在の本編例の手がかりは上の出典を参照。完全な進行過程はなお補足が必要。 [名前攻防](../patterns/姓名攻防与家谱扩写.md)を借用でき、例えばアベンジャーズのメンバーが「滅建国とは誰か」と尋ねる。これは再利用の例であり、確認済みの新しい本編例ではない。
