# サノスとハルクのユニバース

- よくある場面：恋愛、筋トレ、誤解、関係の暴露、作品をまたぐ組み合わせ
- 世界のルール：二人の関係を中心とした作者の版本を記録する。シリーズごとに進度や人物関係が異なる場合があり、一つの連続した筋書きに統合しない。
- 版本の境界：ユニバース分類は重ね合わせることができ、公式のユニバース番号ではない。具体的な作者の版本は個別に記録する。

サノス／ハルクにはすでに連続した CP シリーズのタイトルと合集資料がある。[R03](../../sources/R03.md)の筋トレの本編例でも、ハルクがサノスの反応を引き起こしている。[R11](../../sources/R11.md)のコメントは子孫の世代まで続編を作れるが、推測を本編内の関係に格上げしてはならず、まして他の作者の版本を上書きしてはならない。

## 人物と共用設定

人物は一括して[人物ファイル](../../characters/README.md)を参照し、ここに人物の複製を作らない。保護者の名前や口癖などの共用設定はユニバースをまたいで参照できる。身分の変化と客演は人物ファイルに版本を明記する。

## ストーリーパターンと補足待ち

初期の資料は主に CP シリーズ、目撃、金の貸し借りといったタイトルレベルの手がかりを支えている。[R76](../../sources/R76.md)は現在、狂狂淵淵（クアンクアン・ユエンユエン）第2—4話の伴侣の日常とカモーラの娘呼称を補っており、それによって全話を復元したり血縁の仕組みを統一したりはしていない。詳しくは[二人の関係の項目](../../relationships/灭霸与浩克.md)を参照。告白、誤解、関係の暴露といった実際の本編例の追加を歓迎する。タイトルだけで筋書きを補って書かないこと。

## 隣接するおふざけ版本

[R25](../../sources/R25.md)の身体のダブルミーニングとアントマンのコメントは別の観察可能な手がかりに属する。ある作者の CP 連載に統合するだけの証拠はない。人物を共有していても、単話の関係、場所、結末がすべて同じとは限らない。

## 作者の家族線とその他の偏愛版本

[カモーラ](../../characters/卡魔拉.md)は R76 の連載で娘と呼ばれており、その家族身分は人物ファイルと関係ファイルに書き戻す。ユニバースごとに人物を複製はしない。[R82](../../sources/R82.md)の店主サノスがハルクにケーキを無料で渡す話、[R83](../../sources/R83.md)の手描きの成人後日談はそれぞれ別の作者に属し、個別に記録して一つの共用家族史に合成しない。
