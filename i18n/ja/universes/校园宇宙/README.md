## 人物と共通設定

人物は[人物ファイル](../../characters/README.md)で一括して参照し、ここに人物の複製を作らない。親の名前や口癖などの共通設定はユニバースをまたいで引用できる。身分の変化と客演は人物ファイルに版本を明記する。
