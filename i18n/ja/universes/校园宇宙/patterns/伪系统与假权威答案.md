# 偽システムと偽の権威ある答え

- 類型：キャンパス専属の本編例の仕組みの要約。他のユニバースで再利用する場合は、権威の出所・使える技術・関係を別途確認する。
- 人物：[サノス](../../../characters/灭霸.md)、[アイアンマン](../../../characters/钢铁侠.md)、[ジャービス](../../../characters/贾维斯.md)、[ドクター・ストレンジ](../../../characters/奇异博士.md)。
- 根拠：[R52](../../../sources/R52.md)、[R53](../../../sources/R53.md)。文字起こしを補助にした読解とキーフレームの抜き取り確認による。

## 変形一：偽システムによる誘導

悪友が裏でシステムを構築する → 主人公は独自の能力／報酬を得たと思う → ポイントとクエストのフィードバックが行動を促す → 演出がエスカレートする → 大賞が期待と合わない → いたずらが露見し、結末を負う。

R52ではアイアンマン、ジャービス、ドクターが装置と状況に関わり、サノスはクエストに従って行動する。「システムが存在する」と「システムの言うことが本当だ」は分けて扱う。この作品ではクラスメイトが作った詐欺であり、真正のシステムユニバースを自動的に成立させるものではない。

## 変形二：偽の権威ある答え

主人公が何度も答え合わせをする → 仲間が答えを優等生の提供として装う → 一瞬もっともらしく見える／通用しない → 公式の答えや不在の事実が源を暴く → 謝罪と弁償 → 主人公が次の科目を尋ね、習慣が結末のオチになる。

R53では隣のスーパーマンを答えの権威と見なすが、彼は詐欺的な言葉の中のラベルにすぎず、これだけではスーパーマンに確認済みの優等生属性を設定できない。

## 共通の仕組みと境界

どちらも主人公が信じる権威を利用して情報のずれを仕掛けるが、課題の演出・試験後の不安・露見の仕方は異なる。要約はすべての作品が全段階を取るという意味ではなく、悪友が無限の技術を持つわけでもない。[いたずらと反撃](../../patterns/整蛊与反制.md)と相互参照でき、人物設定を別に複製する必要はない。
