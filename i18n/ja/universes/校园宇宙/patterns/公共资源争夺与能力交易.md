# 公共資源の争奪と能力の取引

- 類型：キャンパス専属の本編例。レストランや公共施設などの日常場面に借用できるが、人物の身分は別途確認する。
- 人物：[サノス](../../../characters/灭霸.md)、[ロケット・ラクーン](../../../characters/小浣熊.md)、[ドクター・ストレンジ](../../../characters/奇异博士.md)および他のクラスメイト。
- 根拠：[R54](../../../sources/R54.md)、コイン式ドライヤーの本編例の音声とキーフレーム。

## どのように展開するか

限られた設備と順番待ちのルール → 各人が使用資格・所要時間・費用について異なる思惑を持つ → 身体的特徴や超能力が配分に影響する → 誰かが技術と引き換えに報酬を求める／便宜を図る → 集団が再調整するか反撃する。

R54では坊主頭、ラクーンの毛量、コインを取り戻す呪文が同じ設備の使用衝突に入り込む。キャラクターが同時に同じ目標を争い、待つ者・使う者・取引する者が互いに影響し合うことで、無関係な台詞を順番に並べるより集団の関係が立ち上がる。

## 境界

これは本編の仕組みの要約であり、特定の費用・呪文のコスト・身体ネタを恒久的な世界ルールとして書くものではない。同種の施設を使うのに新しいユニバースを開く必要はない。場面を変えるときは、まずルールと誰がそのルールを知っているかを説明する。

関連：[超能力の日用品化](../../patterns/超能力与神器日用品化.md)。

## 共有スマホはどう配分の不均衡になるか

[R77](../../../sources/R77.md)前半：スパイダーマンが元々スマホを所持 → 秘密と充電場所と引き換えに使用権を渡す → 仲間が交代で借りる → 元の持ち主がかえって遊べない。後半：全員がスマホを持参 → ドクターの借用が断られる → 教師が端末を確認 → ドクターの仕返しは自分に遊ばせないこと。通報にはその回の動機があり、すべての作者の性格として固定しない。

[R73](../../../sources/R73.md)の雪の日の寮では、資源にはスーツの加熱・オフライン映画・モバイルバッテリーも含まれ、火鍋では仲間が買い出しを分担する。キャラクターはそれぞれ資源や課題を持ち、協力して初めて筋が進む。ソーがモバイルバッテリーを渡すことは、神力発電が確認されたことにはならない。[R82](../../../sources/R82.md)のゲームの労務でおごりと交換するのも、義理の借りと使用権の変形である。
