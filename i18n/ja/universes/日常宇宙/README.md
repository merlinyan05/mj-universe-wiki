# 日常ユニバース

- よくある場面：レストラン、広場、食事、仕事、寮、生活上の葛藤
- 世界のルール：レストラン、広場、飲食、仕事と生活の衝突。他のユニバースのネタや関係を重ねることができる。
- 版本の境界：ユニバース分類は重ね合わせることができ、公式のユニバース番号ではない。具体的な作者の版本は個別に記録する。

振り返りコメントにはデブ・スパイダーマン、67レストラン、67広場、弁当、飲み物、カンフーなどの要素が挙がる。[R08](../../sources/R08.md)これは分岐の手がかりであり、完全な源流考証ではなく、唯一の最初の制作者や最早の日付を断定する根拠にもならない。

## 人物と共用設定

人物は一括して[人物ファイル](../../characters/README.md)を参照し、ここに人物の複製を作らない。保護者の名前や口癖などの共用設定はユニバースをまたいで参照できる。身分の変化と客演は人物ファイルに版本を明記する。

## ストーリーパターンと補足待ち

既存の材料は場所と日常要素を振り返るコメントであり、レストランやアルバイトの決まった流れを要約するのに十分な本編例はまだ確認できていない。[共用の物語の仕組み](../patterns/README.md)を参考にし、補足する際は実際の場面と人物の版本を明記する。

## 67レストランのルール版本

今回はレストランのまとめを直接開いてコメントを読み、視聴者がピエロの客引きと完食の賞罰を場のルールとして語り、最後の一口をわざと残す逆の遊びまであることを確認した。[R27](../../sources/R27.md)は現時点でもコメントの要約であり、これによって各作者の具体的な罰則を統一するものではない。

入口：[日常のストーリーパターン](patterns/README.md)・[67レストランのルールと抜け穴](patterns/67餐厅的规则与钻空子.md)。

## 配達・店主・身分の違い

[R82](../../sources/R82.md)には週末の配達で小遣いを稼ぐスパイダーマンと、小さな売店を営むサノスがいる。[R74](../../sources/R74.md)には別にフューリーという売店の店主がいる。仕事、小遣い、客への扱いの差が日常の衝突を生み、キャンパスの教師やクラスメイトの身分を自動的に継承するわけではない。人物は[スパイダーマン](../../characters/蜘蛛侠.md)、[サノス](../../characters/灭霸.md)、[ニック・フューリー](../../characters/尼克·弗瑞.md)を個別に参照。
