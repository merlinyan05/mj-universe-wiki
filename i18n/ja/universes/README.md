# ユニバースと物語パターン

人物が資料の主索引です。各人物は [characters](../characters/README.md) で一度だけ管理し、ユニバースページは人物を参照して、ここでの身分・関係・物語のルールを説明します。作者ごとのバージョンは並列でき、唯一の正史を求めません。

各分岐が現実のプラットフォームでどう現れ、どう吸収し合ったかは[起源と伝播史](../docs/MJ_HISTORY.md)を参照してください。「起源／前日譚」というタイトルのキャラクター身世物語は、現実の初出考証と分けて扱う必要があります。本ディレクトリのユニバース区分は資料整理の方法であり、確認済みの歴史的順序を示すものではありません。

## 共通設定、バージョン、カメオ

- 人物の基本、親族の名前、ネタはそれぞれ人物・関係・ネタの項目で管理し、各ユニバースは参照するだけで名簿を複製しません。
- 各パターンには典型ユニバース、再利用できる他のユニバース、変わる条件を明記します。ユニバースをまたぐ借用は、すべての身分を自動的に継承することを意味しません。
- 例えば「滅建国とは誰か」は通常ユニバースにも現れます。このネタは話し手が学生であることを要求せず、それだけでタイムスリップが起きたとも判断できません。
- カメオはどの人物バージョンを使い、どの特徴を引き継ぎ、どの物語に現れるかを明記します。明確な例がない場合は可能な用法としてのみ記録し、起きていないカメオを創作しません。
- 学園ユニバースの教師・生徒関係は他のユニバースを自動的に覆いません。CP バージョンも他の作者を自動的に覆いません。

## 追加のしかた

新しいユニバースはまずルール、既知の例、差異を書き、既存の人物ファイルをリンクします。人物の新しいバージョンはその人物ファイルに書き戻します。ユニバース専用パターンは該当ユニバースの `patterns/` に、共有パターンは本ディレクトリの `patterns/` に置き、それぞれ一つだけ管理します。

テンプレート：[ユニバース](../templates/宇宙模板.md) · [物語パターン](../templates/故事模式模板.md)。例がまだないパターンは Issue で先に提起してよく、索引を埋めるために内容をでっち上げないでください。ユニバースページの詳細は現在中国語で管理しています。

## 確認済みのクロスユニバースとジャンル客演

[クロスユニバース、記憶継承と客演](跨宇宙与客串.md)は、外部からの訪問者、地元の記憶変化、逆方向のタイムスリップ、大席ジャンルの連動を区別し、具体的な作者例を添えます。人物の共用と師弟／CP 関係の継承は別々に判断し、一つのネタを借りたことをタイムスリップと同一視しません。

## 連続作品とリソース条件

[学園作者シリーズ](校园宇宙/作者系列.md)は、雪の日の寮、二人の作者の極寒／終末条件、成人後の続編をまとめて索引します。具体的な小道具と台詞で連続性を築き、作者とシリーズで差異を残します。人物は引き続き人物ディレクトリで一度だけ管理します。
