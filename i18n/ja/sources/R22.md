# R22：ラクーンの情報格差と名簿の威力

- 確認日：2026-11-02
- 出典：[生ビールのラクーンは今度こそ大変だ](https://www.bilibili.com/video/BV1ynx56LEJp/)。
- ページの作者名：星河之源-。署名は出典追跡のためだけに用い、初出を断定する根拠にはしない。
- 実際の範囲：元ページのタイトル、人気コメント、既定の返信。完全視聴はしていない。

## 観察

- コメントは情報ポジションのラクーンが情報格差でやられたと明確に述べ、情報ポジションが反制されうるという視聴者の理解を支える。
- コメントは親の名簿を六つのインフィニティ・ストーンと比較し、名簿の方が役に立つと言う。これは社会的な弱みが戦闘力に勝るという笑いの要約であり、実際の戦闘力の数値ではない。
- コメントは「ラクーンの父はロケット弾ではないか」と明確に問い、抖音の直接コメントと名前の変異を互いに裏付ける。
- 「ゼータはどこへ」「ベリアルのバッジはもういらない」が返信でアントマン不在と「ガントレットはいらない」の文型を再利用する。これはコメントのクロス IP 着せ替えであり、本編の登場としては扱えない。

## 使用境界

タイトル表現、コメント共創、作者返信、本編画面は分けて使う。本記録は完全視聴ではなく、コメントから本編の台詞、カット順、唯一の世界規則を補って書くことはできない。コメント数と高評価数は時間とともに変動し、本記録はそれでサイト全体の好みを推算しない。
