# R71：コミュニティ人物テストの二次創作境界

- 出典：[Audience227/mjti](https://github.com/Audience227/mjti)。
- リポジトリ作成日：2026-11-05。確認日：2026-11-09。
- 実際の範囲：リポジトリの公開情報、README、静的設問／結果データ。コードは実行せず、ページも項目ごとにテストしていない。

これはMJテーマの24問人物テストで、結果は九類の人物と博士の異なる表現で性格記述を組織する。結果ラベルには親世代の名前に近い名前が使われるが、これは作者がテスト用に作った対応であり、人物の父母表に直接移せない。性格記述も確認済みの短劇台詞ではない。

コミュニティ派生ツールの入口として、テーマがインタラクティブテストへ拡張したことを示す。人物設定の考証庫とは認定せず、それによって本プロジェクトの初回検索時の歴史的結論も書き換えない。
