# R10：家族写真と祖父母への続編

- 記録日：2026-11-01

- 出典：[サノス一家の集合写真](https://www.bilibili.com/video/BV1ouxp6REjf/)。
- 確認：動画ページを開きコメントを読んだ。集合写真内のすべての人物と文字をフレーム単位では読んでいない。
- 観察：コメントは二爺爺の滅中正（ミエ・ジョンジェン）を明確に続編し、さらに上の世代である滅衆政（ミエ・ジョンジェン）も現れる。「明日学校で笑える」と家系図ネタを再び学園へつなぐネットユーザーもいる。
- 利用可能な設定：家系図ネタは縦に伸び、朋友圈の公開羞恥の仕組みと結びつく。
- 境界：コメントの曖昧な世代関係はそのまま要約し、代数的に正確な家系図を描かない。
