# R11：筋トレ、注目されるハルク、作者のタイムライン・ネタ

- 記録日：2026-11-01

- 出典：[MJ サノスはハルクの筋トレを見て思わず我慢できない](https://www.bilibili.com/video/BV1RTnY6uEpi/)。
- 確認：タイトル、作者紹介、人気コメントを読める。
- 観察：作者紹介は視聴者がハルクを見たがっていることを強調する。コメントはロキが物語を書き、タイムラインを変えたという説でこの版をからかい、「無迪／無敵ハルク」の同音ネタもある。
- 利用可能な設定：ハルクは戦う役や単なる大男ではなく、見つめられ、サノスの感情反応を引き起こす側になれる。
- 境界：コメントから誰が全宇宙最強かを宣言せず、単一の身体ジョークを全バージョンのルールにしない。
