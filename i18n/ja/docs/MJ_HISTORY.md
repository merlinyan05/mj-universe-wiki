# MJユニバースの起源と伝播史

更新・確認日：2026-11-10。ここでは作品とネタの現実の伝播を記録し、キャラクターの作中の生い立ちやユニバース内の時間線ではない。

現時点では、MJユニバースを**複数の古いネタ、画像、AIショートドラマが段階的に合流したコミュニティの二次創作集合**と理解する方が適切であり、誰か一人が一度に書き上げた統一世界観ではない。これは以下の材料に基づく整理上の判断であり、中国語MJ動画、学園線、あるいは「滅建国」という呼称の唯一の先駆者はなお未確認である。

## 回顧が示す段階と残る論争

R08 の約00:42—03:23の叙述は、初期のデブ・スパイダーマンショート、その後飲食、サーカス／ピエロ、67レストランなどと結びつき、旧ネタを吸収し続け、アベンジャーズのおふざけと学園へ拡張した、というもの。題材の聚合を理解するのに使えるが、その中の月、先駆、伝播の因果はなお段落ごとの原投稿の裏づけを欠く。

R29 の人気コメントは別の記憶順を提示する。デブ・スパイダーマンの後に不焼心、恐怖の貴賓犬、ピエロ、67レストラン、カンフーなどがあり、さらにアベンジャーズへ拡張したという。検索の方向を補うが、一つのコメントで他の作者を覆せず、確認済みの精確な年表に組み上げることもできない。

以下の説はまだ史実として書かない：

- **プラットフォームの集中的な弾圧が学園への転向を招いた**：回顧動画は削除、制限、創作の転向を描写するが、対応するプラットフォーム公告や完全な作品サンプルが得られておらず、規模、原因、唯一の因果を確認できない。
- **あるツール／コンテストが熱潮全体を作った**：本編やコメントで生成ツール、イベント、創作インセンティブに言及されるが、そのような説明が存在することを証明するだけ。公式イベント資料と伝播データが欠ける。
- **すべての版本は一本の動画から来た**：中国語MJ、デブ・スパイダーマン画像、滅建国の父名、アントマンの旧ネタ、学園パターンはそれぞれ別の未解決問題であり、一つの「始祖」結論を共有できない。
- **エフェクトがいつ提供開始／終了したか**：回顧や聚合ページは7月末、8月初、異なる終了日を示す。現時点では同時期ニュースが遊び方を記録したことのみ確認し、精確な運営カレンダーに組み上げない。[R38](../sources/R38.md)
- **MJはMidjourneyの略**：今回の材料では、生成ツール名をコミュニティ呼称の確定した語源と説明する根拠が足りない。
- **Mary JaneとMichelle Jonesは同じ名前**：回顧とコメントで表現が異なる。具体的な映画版本に関わる場合はキャラクター名を確認すべきで、同じ略称の二つの名前を一人に混ぜず、デブ・スパイダーマンが映画のMJだと推断もしない。[R28](../sources/R28.md)、[R34](../sources/R34.md)

## 2026-11-09 補足：ツール、同名大会、架空の前日譚

[R64](../sources/R64.md)は「霊光・新帧」公式大会、政務報道、それをアリのAppに関連づける回顧記事を対照した。公式サイトの主催情報とイベント日は、名称や賞金額だけでAppイベントに統合できない。具体的な対応は公式元ページを待ち、イベントが伝播をどう促したかも別に証明する必要がある。R61の10月6—7日の作品記録は回顧の言う10月8日の節目よりさらに早く、確認済みの一つの因果の鎖としては書かない。

見える霊光ウォーターマークは、ある作品にツールのマークが付いていることを証明できるが、すべてのMJ動画が同じツールで生成されたと逆推はできない。[R49](../sources/R49.md)にはupdream マークの本編例もある。ここでは見えるマークを記録し、ウォーターマークを自動的に完全な制作工程と同一視しない。

旧素材の入口も別々に位置づけた。Marvel公式宣伝映像の題名／チャンネルは回查できるが、今回は原編を完全視聴していない。2017年のアントマン議論、8月のチャットアニメ再現はいずれも[R69](../sources/R69.md)を参照。旧素材の存在、その後の字幕と学園性格の形成は別の問題である。

[R65](../sources/R65.md)の小白の物語は作者が書いたペットの生い立ちで、ユニバース内の前日譚に属する。同じ作者が発展史も制作していても、それを現実の貴賓犬ネタの起源や実際の救助事件にはできない。

## どう補証を続けるか

**より早い原投稿**の貢献を歓迎する：リンク、公開作者署名、公開時間、原発／転載／再アップロードの別、関連時点、そして現有材料より具体的にどこが早いか。コメントは手がかりとしてよく、文脈を添えて「コメントの記憶」と記す。作者の自述と実際に見える作品は別々に記録する。複数の解説が同じ出典を引用しても、複数の独立した証拠にはならない。

新しい材料はまず [sources](../sources/README.md) に入れ、その後本ページを更新する。性格、関係、遊び方は引き続き[人物](../characters/README.md)、[ネタ](../memes/README.md)、[ユニバースと物語パターン](../universes/README.md)で管理し、伝播の時間線を各平行世界共通の筋書き正史にはしない。

## 2026-11-10 補足：より早い投稿と前日譚の境界

[R72](../sources/R72.md)は確認可能なMJ題名のAI視覚投稿を8月26日まで前に広げ、9月のデブ・スパイダーマンとサノスの交流を別々に記録する。内容形態、元ページ日付、作者、ツールマークはそれぞれ保存し、先後順だけで直接の伝承の鎖を立てず、現在の熱度から当時の規模を逆推しない。

[R85](../sources/R85.md)は別に二本の架空の身世前日譚と二つの解説入口を確認する。前日譚の中の過去は現実の先駆と同じではなく、新しい解説ページのAI章要点も作者の逐語発言や公式公告の代わりにはならない。[R80](../sources/R80.md)のある作者の転載対応の自述と、視聴者がマーベルを問い詰めるのは別の証拠であり、それによってプラットフォーム全面凍結を宣言しない。
