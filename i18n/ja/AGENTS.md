# 資料メンテナンスの約束

- まず README.md と CONTRIBUTING.md を読む。単独でクローン・保守・閲覧できる資料リポジトリである。
- 人物資料は characters/ で管理し、ユニバースごとに人物を複製しない。出典の観察は sources/ で管理する。ユニバースとストーリーパターンは universes/ に置き、共用パターンは一か所だけ管理して他のページはリンクで参照する。
- 作者・分岐・単話・コメント共創の異なるバージョンを残す。名前が出たことは親族関係が確定したことを意味しない。
- 証拠の種類と実際の確認範囲を明記する。整理案・推論・独自拡張を、確認済みの本編事実として扱わない。
- 項目を追加・改名したときは、そのディレクトリの README 索引と参照を同時に更新する。
- 画像と短い GIF は特定項目の理解または Wiki 表示に資するものとし、関連項目・用途・出典・バージョン・権利状態を明記する。汎用のスタンプ、壁紙、貼り紙の合集は文字索引と外部リンクのみで紹介し、パッケージ全体は外部に置く。詳細は CONTRIBUTING.md を参照。
- 個人情報、本機のパス、資格情報、私的な会話、他プロジェクトの依存関係、メディア制作設定を加えない。
- python3 scripts/check_docs.py を実行する。チェックは Python 標準ライブラリのみを使い、ネットワークに接続しない。
- 貢献内容は CC BY-SA 4.0 に従う。第三者コンテンツと本リポジトリの独自整理は別々に帰属を表示する。
