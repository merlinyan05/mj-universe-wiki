**MJ Universe Wiki・ネット上で初のオープンソース MJ 宇宙設定集。ネタ好きな皆さんで、人物・性格・関係・世界線・物語のパターンを一緒に補完しましょう！**

滅建国って誰？蟻人はどこへ行った？「こりゃ大変だ」は誰が誰に言うのか？

`mj-universe-wiki` は、ビリビリ（B站）や抖音などのプラットフォーム上の MJ 宇宙／マーベル二次創作ショート動画から、人物の性格、親の名前、家系図、定番ネタ、コメント欄の共同創作を整理したものである。学園、通常宇宙の混沌、日常生活、サノス／ハルクの CP などのバージョンを扱い、設定の確認や台本執筆、動画制作に役立てられるほか、このコミュニティ Wiki の改善にも参加できる。

> 「ネット上で初のオープンソース」という位置づけは、2026-11-01 時点の公開検索に基づく。同じテーマのより早い専用オープンソース設定集は見つかっていませんが、すべてのプラットフォームや未インデックスのプロジェクトを網羅するものではない。より早いプロジェクトをご存じの場合は、Issue で追加・訂正してください。[検索記録](docs/MJ_RESEARCH_NOTES.md)

作者や個別エピソードごとにバージョンが異なる場合がある。本資料庫は差異と出典を残すものであり、すべての作品に唯一の正史を定めるものではない。人物関係、親族の名前、物語の仕組みは、判明している範囲を明記している。訂正と追加の証拠を歓迎する。

本リポジトリは人物・関係・世界線・定番ネタを図版と文章で説明する。画像は具体的な項目の理解を助け、または Wiki を提示するために使い、表紙、人物識別図、関係図、必要なスクリーンショット、動きが必要な短い GIF を収録できる。汎用のリアクション画像、壁紙、ステッカー集は文字索引と外部リンクで紹介し、素材一式はリポジトリ外に置く。

## 台本・動画制作での使い方

1. [人物ファイル](characters/README.md)で役割、性格、関係、行動原則を調べ、必要なバージョンを選ぶ。
2. [ユニバースと物語パターン](universes/README.md)で世界のルールと物語の進め方を決める。共有ネタ、カメオ、特殊バージョンは別途明記する。
3. 各項目の[出典記録](sources/README.md)で元動画、コメント、バージョン差を確認してから、台詞と筋を組み立てる。親族、師弟、コンビの関係を混同しないようにしてください。

人物の外観を確認するときは、[外観参考](../../characters/README.md#外观参考)から映画・ゲーム・二次創作デザインのページへ移動できる。現在は外部リンクのみで、MJ 学園の三面図一式はまだない。リンク先素材の利用範囲は提供元のライセンスに従い、本リポジトリへの索引が許諾を与えるものではない。

人物の反応、関係の細部、物語パターンがまだ不十分な場合は、一行の資料を追加するか Issue を立ててください。元動画からの新しい観察も、次の創作者の助けになる。

## 資料の構成

- `characters/`：人物ごとに完全なファイルを一つ。役割、性格、行動、関係、ユニバースごとの差異を記録する。
- `universes/`：世界のルールと物語パターン。専用パターンは該当ユニバースの下に置き、共有パターンは一か所で管理して相互リンクする。
- `relationships/` と `memes/`：ユニバースをまたいで共有される関係、名前ネタ、口癖。
- `sources/`：元動画、コメント、タイムスタンプ、実際に確認した範囲。

人物はユニバースごとに複製しない。ユニバースごとの差異は人物ファイルに書き戻し、ユニバースページからリンクする。物語パターンはユニバースをまたいで再利用でき、カメオ出演はどの人物バージョンを使うかを明記する。

## 設定を一緒に補完する

**名前一つ、性格一つ、カメオ一回、定番の場面一つだけでも歓迎である。** 世界観を一度に全部整理する必要も、コードを書く必要もない。

- 手がかりはあるがファイルを編集できない：リポジトリの Issues で「設定や出典の追加」を選んでください。出典がなくても「要確認」と明記すれば线索として提出できる。
- 誤りやバージョンの衝突を見つけた：「訂正とバージョン差」を選び、どの項目がどう違うかを説明してください。
- 直接編集したい：該当する人物ファイルを開き、GitHub の編集ボタンから Fork・コミット・Pull Request を作成する。
- Git に慣れている：Fork → ブランチ作成 → commit → 自分の Fork へ push → PR。常任メンテナーには書き込み権限が付与され、本リポジトリで直接ブランチを push して PR を出せる。

ロケット・ラクーンがなぜいつも最初に情報を知るのか、サノスがどう反撃するのか、ユニバースごとの人物の違い、元動画やコメントの細部など、追加を歓迎する。既存の説に対する別バージョンや証拠も歓迎である。

具体的な手順、コピーできるコマンド、貢献例は[貢献ガイド](CONTRIBUTING.md)を参照してください。各項目は独立して管理されており、小さな修正だけでも提出できる。

## 役に立つ記録の書き方

「サノスの父は滅建国」と「浣小麗とは誰か」では得られる情報が違う。前者は親族の方向を明確にし、後者は名前が出てきたことだけを示す。名前の性別や、二人がタイトルに並んでいるという理由だけで家系図を補ってはいけない。

本編設定、作者の補足、コメントでの共同創作、整理上の推論、独自拡張は別々に明記する。公開された直接の証拠がない最初の説は[要確認の提案](sources/E01.md)として別に扱い、新しい出典で改訂できる。

## この設定集を応援する

ここで設定を調べたり、台本を書いたり、動画を作ったりしたら、右上の **Star ⭐** を押してください。後で見つけやすくなり、より多くの同好の人がプロジェクトを知ることができる。

リポジトリを MJ 宇宙の視聴者、ショート動画クリエイター、コメント欄を読むのが好きな人たちに共有してください。名前一つ、ネタ一つ、世界線一つからでも、[Issue や PR](CONTRIBUTING.md)で貢献を始められる。
