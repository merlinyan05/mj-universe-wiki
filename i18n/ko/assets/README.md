# README 시각 자료

- 파일: [MJ 유니버스 표지](../../../assets/images/mj-universe-cover.png).
- 제작 날짜: 2026-11-02.
- 출처: 본 프로젝트가 Agnes Image API로 생성. 모델 `agnes-image-2.5-flash`, 16:9, 2K. 중국어 부제를 교정해도 오자가 남아 최종판은 영어 부제로 바꿨다.
- 내용: 타노스, 로켓 라쿤, 아이언맨이 교실에서 설정집을 둘러싸고 상호작용하며, 칠판의 관계망이 인물 관계와 평행 유니버스를 반영한다.
- 용도: README의 2차 창작 비주얼 표지이며, 본편 스크린샷도 설정 고증의 증거도 아니다.
- 권리 안내: 제3자 캐릭터 형상과 상표는 [제3자 자료 안내](../ATTRIBUTION.md)에 따라 처리한다. 이 저장소의 CC 라이선스는 제3자 캐릭터 권리를 허여하지 않는다.

인물 삼면도와 다면도는 현재 [인물 파일](../../../characters/README.md#外观参考)에 외부 링크로 정리되어 있으며 이미지 본체는 추가하지 않았다. 이 표지도 캐릭터 삼면도나 통일 의상으로 사용하지 않는다.
