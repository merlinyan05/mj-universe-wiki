# 유니버스와 스토리 패턴

인물이 자료의 주 색인입니다. 각 인물은 [characters](../characters/README.md)에서 한 번만 관리하고, 유니버스 페이지는 인물을 참조하며 이곳의 신분·관계·이야기 규칙을 설명합니다. 작가별 버전은 나란히 둘 수 있고 유일한 정사를 추구하지 않습니다.

각 분기가 실제 플랫폼에서 어떻게 등장하고 서로 흡수했는지는 [기원과 전파사](../docs/MJ_HISTORY.md)를 참고하세요. "기원/프리퀄" 제목의 캐릭터 신상 이야기는 현실 최초 고증과 분리해야 하며, 이 디렉터리의 유니버스 구분은 자료 정리 방식일 뿐 확인된 역사적 순서를 뜻하지 않습니다.

## 공통 설정, 버전, 카메오

- 인물 기본, 친족 이름, 밈은 각각 인물·관계·밈 항목에서 관리하고, 각 유니버스는 이를 참조할 뿐 명단을 복제하지 않습니다.
- 각 패턴에는 대표 유니버스, 재사용할 수 있는 다른 유니버스, 달라지는 조건을 명시합니다. 유니버스를 넘는 차용이 모든 신분을 자동으로 상속한다는 뜻은 아닙니다.
- 예를 들어 "멸건국은 누구"는 일반 유니버스에도 나올 수 있습니다. 이 밈은 화자가 학생일 것을 요구하지 않으며, 그것만으로 시간 이동이 일어났다고 판단할 수도 없습니다.
- 카메오는 어떤 인물 버전을 쓰고 어떤 특징을 이어받으며 어느 이야기에 나오는지 명시합니다. 명확한 예시가 없으면 가능한 용법으로만 기록하고 일어나지 않은 카메오를 창작하지 않습니다.
- 캠퍼스 유니버스의 교사·학생 관계는 다른 유니버스를 자동으로 덮지 않습니다. CP 버전도 다른 작가를 자동으로 덮지 않습니다.

## 추가하는 방법

새 유니버스는 먼저 규칙, 알려진 예시, 차이를 쓰고 기존 인물 파일을 링크합니다. 인물의 새 버전은 해당 인물 파일에 다시 씁니다. 유니버스 전용 패턴은 해당 유니버스의 `patterns/`에, 공유 패턴은 이 디렉터리의 `patterns/`에 두고 각각 한 번만 관리합니다.

템플릿: [유니버스](../templates/宇宙模板.md) · [스토리 패턴](../templates/故事模式模板.md). 예시가 아직 없는 패턴은 Issue로 먼저 제안해도 되며, 색인을 채우기 위해 내용을 지어내지 마세요. 유니버스 페이지의 세부 내용은 현재 중국어로 관리합니다.

## 확인된 크로스 유니버스와 장르 카메오

[크로스 유니버스, 기억 상속과 카메오](跨宇宙与客串.md)는 외부 방문자, 지역 기억 변화, 역방향 타임슬립, 대형 프랜차이즈 연동을 구분하고 구체적인 작가 예시를 붙입니다. 인물 공유와 사제/CP 관계 상속은 따로 판단하며, 밈 하나를 빌린 것을 타임슬립과 동일시하지 않습니다.

## 연속 작품과 자원 조건

[캠퍼스 작가 시리즈](校园宇宙/作者系列.md)는 눈 오는 날 기숙사, 두 작가의 혹한/종말 조건과 성인 후속편을 모아 색인합니다. 구체적인 소품과 대사로 연속성을 세우고 작가와 시리즈로 차이를 남기며, 인물은 계속 인물 디렉터리에서 한 번만 관리합니다.
