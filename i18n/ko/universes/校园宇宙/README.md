## 인물과 공통 설정

인물은 [인물 파일](../../characters/README.md)에서 일괄 조회하고 여기에 인물 복제를 만들지 않는다. 부모 이름, 말버릇 같은 공통 설정은 유니버스를 넘어 인용할 수 있다. 신분 변화와 카메오는 인물 파일에 버전을 명시한다.

## 장면, 단계, 새로운 패턴

이번에 수업 규율, 통학 보급, 자원 대기, 운동회, 대학 이후를 보충했다. 캠퍼스의 장면/단계와 작가 버전으로 다루며 기계적으로 유니버스를 난립시키지 않는다. 같은 외형도 관계를 자동 상속하지 않는다. 자세한 내용은 [크로스 유니버스와 카메오](../跨宇宙与客串.md).

## 작가 시리즈와 세계 조건 (2026-11-10)

[작가 시리즈 색인](作者系列.md)은 눈 오는 날 기숙사의 대야/탕위안 연결, 두 작가의 혹한 조건, 손그림 성인 후속편을 보충한다. 인물은 계속 독립 관리: 캡틴 아메리카의 반장과 책임, [로키](../../characters/洛基.md)의 방문은 [R73](../../sources/R73.md), [닉 퓨리](../../characters/尼克·弗瑞.md)의 교사 버전은 [R74](../../sources/R74.md), [슈퍼맨](../../characters/超人.md)의 기숙사 점검은 [R88](../../sources/R88.md). 교사 버전, 점주 버전, 점검 행동을 자동으로 고정 직무에 합치지 않는다.
