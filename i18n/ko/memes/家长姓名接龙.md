# 부모 이름 릴레이

"누구누구는 누구냐"는 표면상 질문이지만, 실제로는 이미 드러난 이름을 반복해서 말한다. 네티즌은 이어서 부모, 후손, 조부모로 확장하고 정보 제공자까지 역추적한다. [R02](../sources/R02.md), [R06](../sources/R06.md), [R07](../sources/R07.md), [R10](../sources/R10.md), [R13](../sources/R13.md)

이름은 [인물 파일](../characters/README.md)에서 관리하고, [관계 미확정 후보](../relationships/待核对姓名.md)를 억지로 가계도에 채우지 않는다.
