# R71: 커뮤니티 인물 테스트의 2차 창작 경계

- 출처: [Audience227/mjti](https://github.com/Audience227/mjti).

- 실제 범위: 저장소 공개 정보, README, 정적 문항/결과 데이터. 코드는 실행하지 않았고 페이지도 항목별로 테스트하지 않았습니다.

이는 MJ 테마의 24문항 인물 테스트로, 결과는 아홉 유형의 인물과 박사의 서로 다른 표현으로 성격 설명을 구성합니다. 결과 라벨에는 부모 세대 이름에 가까운 이름이 쓰이지만 이는 작가가 테스트를 위해 만든 매핑이며 인물의 부모표에 바로 옮길 수 없습니다. 성격 설명도 확인된 단극 대사가 아닙니다.

커뮤니티 파생 도구 입구로서 테마가 인터랙티브 테스트로 확장되었음을 보여 줍니다. 인물 설정 고증库로 인정하지 않고, 그것으로 이 프로젝트의 최초 검색 당시 역사적 결론도 다시 쓰지 않습니다.
