# R22: 라쿤의 정보 격차와 명단의 위력

- 확인일: 2026-11-02
- 출처: [생맥주 라쿤은 이번에 큰일 났다](https://www.bilibili.com/video/BV1ynx56LEJp/).
- 페이지 작가 표기: 星河之源-. 서명은 출처 추적에만 쓰며 최초 창작을 단정하는 근거로 삼지 않습니다.
- 실제 범위: 원 페이지 제목, 인기 댓글, 기본 답글. 전체 시청은 하지 않았습니다.

## 관찰

- 댓글은 정보 포지션의 라쿤이 정보 격차로 당했다고 분명히 말해, 정보 포지션이 반격받을 수 있다는 시청자 이해를 뒷받침합니다.
- 댓글은 부모 명단을 여섯 개의 인피니티 스톤과 비교하며 명단이 더 쓸모 있다고 말합니다. 이는 사회적 약점이 전투력을 이긴다는 웃음의 요약이며 실제 전투력 수치가 아닙니다.
- 댓글은 "라쿤 아버지는 로켓탄 아니야?"라고 분명히 물어 더우인 직접 댓글과 이름 변형을 서로 뒷받침합니다.
- "제타는 어디 갔나", "베리알 배지는 이제 필요 없어"가 답글에서 앤트맨 부재와 "건틀릿은 필요 없어" 문형을 재사용합니다. 이는 댓글의 크로스 IP 갈아입히기이며 영상 내 등장으로 볼 수 없습니다.

## 사용 경계

제목 표현, 댓글 공동 창작, 작가 답글, 영상 내 화면은 따로 사용합니다. 이 기록은 전체 시청이 아니며, 댓글로 영상 내 대사, 샷 순서, 유일한 세계 규칙을 보충해 쓸 수 없습니다. 댓글 수와 좋아요 수는 시간에 따라 변하며, 이 기록은 그것으로 사이트 전체 선호를 추산하지 않습니다.
