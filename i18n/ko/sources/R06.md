# R06: 아버지 이름 정리, 댓글 이미지, 학력 동음이의

- 기록일: 2026-11-01

- 출처: [한 번에 모든 슈퍼히어로의 아버지를 알아보기](https://www.bilibili.com/video/BV1AGxg6KEAL/).
- 확인: 댓글을 직접 훑어보고 첫 인기 댓글에 첨부된 텍스트 이미지를 실제로 확인했습니다. 이미지에는 열 줄의 캐릭터와 이름 화살표가 나열되고 닥터 스트레인지가 두 가지 이름 버전으로 등장합니다. 영상 화면을 발췌해 보니 자막에서도 앤트맨의 아버지가 의대용(蟻大勇)임을 분명히 제시했습니다.
- 관찰: 이미지 속 생활 이름 릴레이와 댓글 속 "치빠", "기이석사", "성궁철도" 같은 동음 릴레이가 공존합니다. 토르 답글란에서는 원작의 아버지 오딘과 뇌원조(雷援朝)를 겹쳐 하나의 "중국식 이름" 농담으로 만듭니다.
- 활용 가능한 설정: 명단에는 서로 다른 작명 기제가 있으며 같은 캐릭터에 두 이름이 있다고 하나를 지울 수 없습니다. 원작을 바로잡는 것 자체도 밈이 됩니다.
- 경계: 댓글 이미지에는 화살표만 있습니다. 아버지 명단으로 읽는 것은 영상 주제에 의존하며, 제목 없는 이미지만으로 각 세대의 관계를 판단할 수 없습니다.
