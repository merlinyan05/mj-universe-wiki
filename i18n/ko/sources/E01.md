# E01: 확인 대기 중인 초기 정리 제안

- 유형: 정리 제안. 공개 원본 영상 증거가 아닙니다.
- 상태: 공개 출처를 보충해야 하며 Issue나 PR로 수정할 수 있습니다.

초기 정리에서는 에인션트 원 선생님, 우등생 닥터 스트레인지, 라쿤을 "최강 정보 포지션", 아이언맨과 라쿤의 파트너 관계, 그리고 "이제 큰일 났다"가 주로 파트너끼리 서로 경고할 때 쓰인다는 점을 제안했습니다.

일부 사례는 댓글과 호응하지만 이 자료만으로 모든 신분, 최고 정도의 표현, 사이트 전체 출현 빈도를 증명할 수 없습니다. 따라서 위 표현은 특정 캠퍼스 버전의 정리 제안으로 남기고 유일한 정사로 삼지 않으며, 파일에 적혔다고 자동으로 "영상 내 설정"으로 격상하지 않습니다.

"우등생", "선생님"처럼 직접적 공개 증거가 아직 부족한 속성은 영상 내 시점이나 작가 설명을 계속 보충해야 합니다. 다른 버전이 있으면 나란히 기록합니다.
