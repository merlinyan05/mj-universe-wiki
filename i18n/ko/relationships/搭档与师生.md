# 파트너·공방·사제 관계

| 관계 | 확인된 용법 | 출처와 범위 |
| --- | --- | --- |
| 로켓 라쿤 ↔ 아이언맨 | 사적으로 품평하고 말을 이어받은 뒤 장난을 실행한다 | [S1](../sources/S1.md), [S5](../sources/S5.md) |
| 파트너 → 타노스 | 구체적인 카피나 약점을 인용하며, 쥐고 있는 정보가 상대의 예상을 뛰어넘는다 | [S1](../sources/S1.md), [S2](../sources/S2.md), [S5](../sources/S5.md) |
| 타노스 → 다른 캐릭터 | 부인·도움 요청·폭로·반격. 늘 당하는 쪽으로 고정되어 있지 않다 | [R05](../sources/R05.md), [R12](../sources/R12.md) |
| 멸건국 → 타노스 | 아버지와 아들. 연장자가 개입하면서 사건이 커진다 | [S2](../sources/S2.md), [S3](../sources/S3.md), [S5](../sources/S5.md) |
| 에인션트 원 → 학생 | 임시 반장을 임명하고 규율 위반과 학부모 호출을 처리한다. 상설 담임직은 별도로 확인 | [R40](../sources/R40.md), [R44](../sources/R44.md) |
| 닥터 스트레인지 ↔ 반 친구 | 반 1등, 임시 반장, 순간이동 구조는 각각 영상 사례가 있는 표현 | [R43](../sources/R43.md), [R44](../sources/R44.md), [R16](../sources/R16.md) |
| 아이언맨 → 타노스 | 임시로 로켓의 비밀을 역추적하는 것을 돕기도 한다. 영구적인 대립은 아니다 | [R42](../sources/R42.md) |
| 토르 ↔ 기숙사 동기 | 통학생 장보기, 교문 인계, 모임 | [R45](../sources/R45.md) |
| 닥터 페이트 → 옆 DC반 | 단일 작성자의 제목／영상 사례 속 담임. 가족 정보는 [인물 파일](../characters/命运博士.md) 참조 | [R68](../sources/R68.md) |

친족 이름은 해당 [인물 파일](../characters/README.md)을 갱신하고, 여기에 가계도를 복제하지 않는다.
