# 자료 관리 규칙

- 먼저 README.md와 CONTRIBUTING.md를 읽는다. 단독으로 복제·유지·열람할 수 있는 자료 저장소이다.
- 인물 자료는 characters/ 에서 관리하고 유니버스마다 인물을 복제하지 않는다. 출처 관찰은 sources/ 에서 관리한다. 유니버스와 스토리 패턴은 universes/ 에 두고, 공용 패턴은 한 곳에서만 관리하며 다른 페이지는 링크로 참조한다.
- 작가, 분기, 단편, 댓글 공동 창작의 서로 다른 버전을 남긴다. 이름이 등장했다고 해서 친족 관계가 확정된 것은 아니다.
- 증거 유형과 실제 확인 범위를 밝힌다. 정리 제안, 추론, 창작 확장을 확인된 영상 내 사실로 취급하지 않는다.
- 항목을 추가하거나 이름을 바꾸면 해당 디렉터리의 README 색인과 참조를 함께 갱신한다.
- 이미지와 짧은 GIF는 특정 항목의 이해나 위키 전시에 기여하는 것으로, 관련 항목·용도·출처·버전·권리 상태를 밝힌다. 범용 짤방, 배경 화면, 스티커 모음은 텍스트 색인과 외부 링크로만 소개하고 묶음 전체는 외부에 둔다. 자세한 내용은 CONTRIBUTING.md를 참고한다.
- 개인 정보, 로컬 경로, 자격 증명, 사적 대화, 다른 프로젝트 의존성, 미디어 제작 설정을 넣지 않는다.
- python3 scripts/check_docs.py를 실행한다. 검사는 파이썬 표준 라이브러리만 사용하며 네트워크에 접속하지 않는다.
- 기여 내용은 CC BY-SA 4.0을 따른다. 제3자 콘텐츠와 이 저장소의 독자적 정리는 귀속을 따로 표시한다.
