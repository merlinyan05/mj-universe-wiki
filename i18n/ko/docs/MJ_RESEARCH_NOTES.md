# MJ 유니버스 광범위 조사: 분기, 부모님 이름, 댓글 공동 창작

날짜: 2026-11-01. [자료 내비게이션](MJ_UNIVERSE.md)과 함께 원본 영상, 댓글, 검색의 관찰 범위를 기록한다.

최신 추가 조사: 2026-11-10에 인물 행동, 가족 호칭, 작가 연속선과 8—9월 AI 게시 지점을 보충. 이 페이지 마지막 절, [인물 파일](../characters/README.md), [스토리 패턴](../universes/patterns/README.md), [기원과 전파사](MJ_HISTORY.md)를 참조. 초기 날짜 단락은 당시 확인 범위를 유지하며, 후속 보증을 이전부터 알고 있었던 것처럼 소급 기입하지 않는다.

## 조사 질문과 실제 범위

연구 범위는 수업·캠퍼스, 순수 유니버스, 순수 헛소리 등의 분기를 포함하며, 특히 헐크의 다양한 용법과 댓글에서 이어지는 부모 및 다른 친족 이름에 주목한다.

이번에는 B站과 더우인 영상 페이지의 공개 댓글을 직접 열람하고, B站 댓글 이미지, 일부 답글, 시리즈 합집 제목을 확인했으며, 공개된 웨이보 부모 이름 릴레이 하나를 읽었다. [출처 색인](../sources/README.md)에는 14개의 R 번호 항목이 있으며, 그중 R02와 R14는 기존 출처에 추가된 새 댓글 관찰이고 나머지는 이번 추가분이다. 표본은 목적적 추출이지 무작위 표본이 아니며, 어떤 이름이나 캐릭터 성격의 온라인 비율을 계산하는 데 쓸 수 없다.

더우인 검색 페이지는 로그인을 요구하지만 일부 직접 영상 페이지는 공개 댓글을 읽을 수 있다. 실제로 사용한 것은 읽을 수 있는 직접 영상 페이지다. 로그인, 댓글 작성, 팔로우 상태 변경은 하지 않았다. 일부 페이지는 제한된 댓글만 보여 주며 모든 답글을 읽었다고 볼 수 없다. B站 제목, 댓글, 이미지 문자, 발췌 시청한 영상 프레임은 각각 명시하며, 완주하지 않은 내용을 "완주"로 쓰지 않는다.

## 출처 기록

관찰과 경계는 [독립 출처 파일](../sources/README.md)로 분리했고, 원래 R01–R14, S1–S8 번호는 안정적으로 유지한다. 이번에는 기존 기록을 재구성했을 뿐 외부 페이지를 다시 시청하거나 재확인했다고 주장하지 않는다.

## 최초 공개 전 동종 프로젝트 재조사

재조사 날짜: 2026-11-01. 프로젝트 포지셔닝의 "현재 공개 검색으로 알려진 첫 오픈소스 MJ 유니버스 설정집"은 공개 검색에 기반한 제한적 판단이며, 온라인 최초 공개 순서의 전수 증명이 아니다. 더 이른 동일 주제 저장소를 환영하며 설명을 수정한다.

이번에는 GitHub 저장소 검색을 직접 사용해 이름이나 설명의 `MJ宇宙`, `MJ 宇宙`, `mj-universe`, `滅建国`, `MJ 設定集`을 확인하고 사이트 외 검색으로 GitHub 페이지를 보충했다. 중국어 완전 구문과 설정 관련 쿼리는 일치 저장소를 반환하지 않았고, `mj-universe`는 다른 세계관, 웹사이트, 소프트웨어 프로젝트를 포함한 동명 후보를 반환했다. 저장소 검색 결과는 모든 코드 파일, 다른 플랫폼, 미색인 프로젝트의 완전한 포괄이 아니다.

- [stancap21-lab/MJ-Universe](https://github.com/stancap21-lab/MJ-Universe): 이번 README도 아직 제목만 있음. 이전 파일 확인에서는 다른 가상 세계로 기록했으며, 이름만으로 동일 주제 설정집으로 보지 않는다.

## 2026-11-02: 20분간 원페이지와 댓글 보충

이번에는 정시 목표로 계속 검색·열람·정리했으며, 중점은 B站과 더우인 직접 영상 페이지 및 공개 댓글이다. 새로 [R15–R27 출처 기록](../sources/README.md): B站 9페이지, 더우인 4페이지. 또한 [R02](../sources/R02.md)의 더우인 댓글을 재방문했다. 사이트 외 검색은 입구로만 사용했고, 무관한 영화 정사, 금융 주제, 신뢰할 만한 출처가 없는 집계 페이지는 설정으로 가져오지 않았다.

실제 확인은 주로 제목, 인기 댓글, 기본 답글, 수동으로 펼친 일부 답글 스레드에 의존하고 소량의 영상 프레임으로 보충했다. 이번에 이 영상들을 문장 단위로 완주하지 않았고 각 페이지의 모든 댓글도 다 읽지 않았으므로, 이번 요약을 완전한 줄거리 개요나 온라인 합의로 볼 수 없다. 댓글 작성, 창작자 연락, 팔로우 상태 변경은 하지 않았다.

### 인물과 친족의 새 버전

라쿤, 닥터 스트레인지, 아이언맨, 타노스, 멸건국, 앤트맨, 헐크, MJ와 뚱땡이 스파이더맨 총 8개 파일에 행동, 상호작용, 버전 경계를 보충했다.

- 로켓의 아버지에 "火箭彈" 추가: R02 재방문과 R22 모두 아버지를 명시한 댓글이 있다. "浣內庫"는 R23의 명시적 제목에서 왔다. 각 버전을 유지한다.
- R24 답글은 멸건국의 아버지를 "滅建軍"과 "滅火器" 둘 다로 부른다. 후자는 기존 타노스 어머니와 이름이 같아 억지로 하나의 가계도로 합칠 수 없다.
- R24에 "타노스 아버지는 聶建国"이라는 댓글이 있어 원자를 유지하고 동음이의나 오기 가능성을 표시하며, 기존 표준 입구를 대체하지 않는다.
- 浣玉芳, 浣麗娟, 浣介石, 奇建軍, 滅淑芬, 滅紅梅 등은 아직 친족 방향이 없어 확인 대기 목록에 들어간다.
- "奇異中專／奇異大專"은 본인 학력 호칭에 대한 놀림이며 실제 학력이나 부모 이름으로 직접 다루지 않는다.

### 아직 확인이 필요한 내용

"黃金巨蟒과 초콜릿 소스"는 직접 영상 페이지 제목을 찾았지만 로켓이 가장 먼저 아는 영상 내 증거는 보지 못했다. 정보 포지션의 설명 예시와 구체적 영상 사례의 구분을 유지한다. [R26](../sources/R26.md)

헐크 관련 신체적 중의, 푸들에 의한 IP 간 제재, 67 레스토랑의 완전한 인물 관계는 아직 영상 내 시점이 더 필요하다. 고일 교사와 박사 우등생이라는 초기 주장은 이번에 충분한 직접 신분 대사를 보충하지 못했으며, 확인 결과를 조작하지 않는다.

곁가지로 [학교가 삭발을 요구](https://www.bilibili.com/video/BV1hMsd6rE4z/)의 제목, 약 00:15 화면, 소량의 댓글을 발췌 확인했다: 삭발한 아이언맨과 타노스의 손이 보이고, 댓글은 다시 앤트맨이 어디 갔는지 묻는다. 이번에 전후 인과를 문장 단위로 확인하지 않아 완전한 줄거리 공식은 아직 요약하지 않는다.

### 확인 방법 소결

단편 자동 연속 재생은 다른 영상으로 넘어가므로, 만날 때 현재 제목과 실제 주소를 재확인했다. R20은 실제로 댓글을 읽은 페이지로建档했고, R23은 연속 재생 후의 합집 댓글을 원본에 귀속하지 않았다. 검색 요약과 현재 댓글이 불일치할 때는 각자의 가시 범위로 명시하며, 작가가 여전히 공개 확인하는 주장으로 보충해 쓰지 않는다.

### 이번 반영

README, 자료 내비게이션, 기여 입구, 유니버스 목록, 뚱땡이 스파이더맨, 멸건국, 앤트맨 밈 항목을 동기화해 링크했다. 현실 전파사는 평행 세계 설정을 대체하지 않으며, 원본 영상, 전체 전사, 제3자 이미지는 이번 자료 갱신과 함께 수록하지 않는다.
