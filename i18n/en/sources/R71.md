# R71: The boundary of derivative works from a community character test

- Source: [Audience227/mjti](https://github.com/Audience227/mjti).
- Repository creation date: 2026-11-05; verification date: 2026-11-09.
- Actual scope: the repository's public information, README and static question/result data; the code was not run and the pages were not tested item by item.

This is a 24-question character test on the MJ theme, whose results organize personality descriptions with nine character types and the Doctor's different manifestations. The result labels use some names close to parent-generation names; this is a mapping the creator made for the test and cannot be moved directly into a character's parent table; the personality descriptions are also not verified short-drama dialogue.

It can serve as a community derivative tool entry, showing that the theme has expanded into interactive tests. It is not certified as a character-setting research database, nor does it rewrite the historical conclusions of this project's first search.
