# Universes and story patterns

Characters are the main index of the material: each character is maintained once in [characters](../characters/README.md), and universe pages reference characters and explain identities, relationships and story rules. Versions by different creators may stand side by side; there is no single canon.

See [origins and spread](../docs/MJ_HISTORY.md) for how each branch appeared on real platforms and how they absorbed each other. Character backstories titled "origin/prequel" must be kept separate from research into real-world firsts; the universe categories here are an organizing method for the material and do not represent verified historical order.

## Shared settings, versions and cameos

- Character basics, relatives' names and memes are maintained in character, relationship and meme entries respectively; each universe references them instead of duplicating name lists.
- Each pattern states its typical universe, which other universes it can be used in, and which conditions change. Borrowing across universes does not automatically inherit every identity.
- For example, "who is Mie Jianguo" can also appear in the standard universe; the joke does not require the speaker to be a student, nor does it alone prove that a crossover happened.
- Cameos state which version of the character is used, which traits carry over and in which story they appear; without a clear example, record only a possible use and do not invent a cameo that has not happened.
- Teacher-student relationships in the campus universe do not automatically cover other universes; CP versions do not automatically cover other creators.

## How to add material

For a new universe, first write the rules, known examples and differences, and link existing character files; new versions of a character are written back into that character's file. Universe-specific patterns go in that universe's `patterns/`; shareable patterns go in this directory's `patterns/`, each maintained once.

Templates: [universe](../templates/宇宙模板.md) · [story pattern](../templates/故事模式模板.md) (Chinese). Patterns still missing examples can start as an Issue; do not invent content just to fill the index.

## Verified cross-universe and cross-genre cameos

[Cross-universe, memory inheritance and cameos](跨宇宙与客串.md) distinguishes outside visitors, local memory changes, reverse crossovers and cross-franchise tie-ins, with specific creator examples. Shared characters and teacher-student/CP relationship inheritance are judged separately, so borrowing one meme is not equated with a crossover.

## Continuous works and resource conditions

[Campus creator series](校园宇宙/作者系列.md) indexes the snowy-dorm arc, two creators' extreme-cold/apocalypse conditions and adult sequels. Continuity is established through specific props and dialogue, and differences are preserved by creator and series; characters are still maintained only once in the character directory.
