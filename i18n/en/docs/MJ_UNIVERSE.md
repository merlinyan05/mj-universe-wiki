## Evidence and versions

In-video canon, creator's supplements, comment co-creation, editorial inference and original expansion are labelled separately. For the initial claims that lack direct public evidence see [E01](../sources/E01.md); corrections and further evidence are welcome.

One fact keeps one maintenance location: character and relative names update the character files, source observations update the source files, and other entry points only link. For how to take part see the [contribution guidelines](../CONTRIBUTING.md).
