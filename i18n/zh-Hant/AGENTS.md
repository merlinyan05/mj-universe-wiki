# 資料維護約定

- 先讀 README.md 和 CONTRIBUTING.md；這是可以單獨複製、維護和閱讀的資料倉庫。
- 人物資料維護在 characters/，不按宇宙複製人物；來源觀察維護在 sources/。宇宙與故事模式在 universes/，共用模式只維護一份，其他頁面透過連結引用。
- 保留作者、分支、單集與評論共創的不同版本；名字出現不等於親屬身分明確。
- 標明證據類型與實際核對範圍；整理提案、推斷和原創擴寫不能當作已核對的片內事實。
- 新增或改名條目時同步更新所在目錄 README 索引與引用。
- 圖片與短 GIF 服務於具體條目的理解或 Wiki 展示，註明關聯條目、用途、來源、版本和權利狀態；通用表情包、壁紙與貼圖合集僅以文字索引和外鏈介紹，整包檔案放在外部，詳見 CONTRIBUTING.md。
- 不加入私人資訊、本機路徑、憑證、私人對話、其他專案依賴或媒體生產設定。
- 執行 python3 scripts/check_docs.py；檢查只使用 Python 標準函式庫，不存取網路。
- 貢獻內容遵循 CC BY-SA 4.0；第三方內容與本倉庫原創整理區分歸屬。
