# R03：薩諾斯與綠巨人的 CP 連載

- 記錄日期：2026-11-01

- 來源：[【MJ】薩諾斯和綠巨人 CP！（2）](https://www.bilibili.com/video/BV1rpnP6iEgW/)，作者「瘋狂淵淵」。
- 核對：直接打開影片頁，讀熱門留言及預設展開的回覆；合集介面列出第 1–4 集，以及奇異博士目擊、兩人借錢等延伸片名。
- 觀察：這已經是可連續生產的關係設定。留言繼續把卡魔拉的外觀接進家庭猜想，也有人用洛基改時間線的說法來解釋。
- 可用設定：薩諾斯與浩克可以在某個作者版本中有固定關係線；奇異博士等熟人可以目擊、發現、傳播。
- 邊界：沒有據標題判定每集誰追誰、雙方關係進度、具體親子關係；不把性暗示留言展開成統一身體設定。
