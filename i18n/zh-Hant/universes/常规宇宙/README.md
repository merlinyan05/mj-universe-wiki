# 常規宇宙／復聯整活

- 常見場景：無限手套、響指、集合、作戰準備、能力反制
- 世界規則：以能力、無限手套、響指和復聯行動為背景；這裡是二創分類，不等於電影正史。
- 版本邊界：宇宙分類可以疊加，不是官方宇宙編號；具體作者版本分別記錄。

滅霸提前準備與復聯反制互相升級，奇異博士出計策；評論以蟻人缺席、其他時間線、許多結局接梗。[R04](../../sources/R04.md)「告老師」「手套不要了」等校園話語也可被借用，但不因此將所有人都設成學生。

## 人物與共用設定
