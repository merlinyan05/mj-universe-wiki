# 宇宙與故事模式

人物是資料的主索引：每個人物的檔案只在 [characters](../characters/README.md) 維護一份，宇宙頁面引用人物，並說明這裡的身分、關係與故事規則。不同作者的版本可以並列，不追求唯一正史。

各分支在現實平台上怎樣出現、怎樣互相吸收，見[起源與傳播史](../docs/MJ_HISTORY.md)。帶「起源／前傳」標題的角色身世故事，須與現實首創考據分開；本目錄的宇宙劃分是資料組織方式，不代表已證實的歷史先後。

## 共用設定、版本與客串

- 人物基礎、親屬姓名和梗分別維護在人物、關係和梗條目；各宇宙引用，不複製多份姓名表。
- 具體模式註明典型宇宙、還可用於哪些宇宙，以及使用時哪些條件發生變化。跨宇宙借用不等於自動繼承全部身分。
- 例如「滅建國是誰」也可以出現在常規宇宙；這句梗不要求說話者是學生，也不能僅憑它判斷發生了穿越。
- 客串註明人物採用哪個版本、沿用哪些特點、在哪個故事出現；沒有明確片例時只記作可能用法，不虛構已發生的客串。
- 校園宇宙裡的教師、學生關係不自動覆蓋其他宇宙；CP 版本也不自動覆蓋其他作者。

## 怎樣補充

新增宇宙先寫規則、已知片例與差異，連結已有的人物檔案；人物的新版本寫回該人物檔案。宇宙專屬模式放在該宇宙的 `patterns/`，可共享模式放在本目錄的 `patterns/`，各自只維護一份。

範本：[宇宙](../templates/宇宙模板.md) · [故事模式](../templates/故事模式模板.md)。暫缺片例的模式可以先提 Issue，不必為了填目錄編造內容。宇宙頁詳細內容目前以簡體中文維護。

## 已核跨宇宙與題材客串

[跨宇宙、記憶繼承與客串](跨宇宙与客串.md)區分外來訪客、本地記憶變化、反向穿越和大席題材聯動，附具體作者片例。人物共用與師生／CP 關係繼承分別判斷，避免把借一句梗等同於穿越。
