# 偽系統與假權威答案

- 類型：校園專屬片例的機制歸納；其他宇宙複用時另核權威來源、可用技術與關係。
- 人物：[滅霸](../../../characters/灭霸.md)、[鋼鐵俠](../../../characters/钢铁侠.md)、[賈維斯](../../../characters/贾维斯.md)、[奇異博士](../../../characters/奇异博士.md)。
- 依據：[R52](../../../sources/R52.md)、[R53](../../../sources/R53.md)，轉寫輔助閱讀與關鍵幀抽查。

## 變體一：偽系統誘導

損友在後台搭建系統 → 主角以為獲得獨有能力／獎勵 → 積分與任務回饋誘導繼續行動 → 表演升級 → 大獎與預期不符 → 揭穿整蠱並承擔後果。

R52 中，鋼鐵俠、賈維斯和博士參與裝置與情境，滅霸根據任務行動。「系統存在」與「系統說的是真的」分開：該片是同學造的騙局，不自動建立真實系統宇宙。

## 變體二：假權威答案

主角反覆對答案 → 同伴把答案包裝成學霸提供 → 短暫看來可信／騙不過 → 官方答案或缺席事實揭穿來源 → 道歉賠禮 → 主角又問下一科，習慣形成結尾回扣。

R53 把隔壁超人當作答案權威，但他是騙詞中的標籤，不能單憑此處給超人建立已證實的學霸屬性。

## 共同機制與邊界

二者都借主角相信的權威安排資訊差，但任務表演、考後焦慮與揭穿方式不同。歸納不等於每部作品都採用全部步驟，損友也不自動擁有無限技術。可和[整蠱與反制](../../patterns/整蛊与反制.md)互相引用，不另複製一份人物設定。
