# 文案意象字面化與評論續演

- 類型：跨宇宙共用；校園版本最容易接「明天上學」。
- 依據：[R15](../../sources/R15.md)、[R17](../../sources/R17.md)，另見 [R14](../../sources/R14.md)。本輪主要核對評論與回覆，不冒充片內完整流程。

## 如何展開

真誠表達情緒 → 損友抽出一個具體名詞 → 把比喻按字面解釋 → 給本人換上外號 → 第三人繼續接話或預告次日見面 → 當事人護面子、威脅撤回小福利。

評論中的「刺」被接成刺蝟、海膽；「堅硬外殼」被接成烏龜。笑點不是隨便辱罵，而是對方剛說過的話立刻成為能反覆呼叫的稱呼。[R15](../../sources/R15.md)、[R17](../../sources/R17.md)

## 人物與接話關係

[滅霸](../../characters/灭霸.md) 需要真的想表達情緒，才有被熟人拆解的落差。[鋼鐵俠](../../characters/钢铁侠.md) 和[小浣熊](../../characters/小浣熊.md) 可以先交換理解，再一人起外號、一人把外號放進實際場景。不要讓所有人只是複讀同一句。

R15 的一條回覆直接分配鋼鐵俠、火箭、滅霸台詞，最後用辣條斷供收尾；這是觀眾在評論中寫出的版本，不是該影片已核實的對白。

若採用「這下玩大了」作預警，先明確哪位搭檔發現後果、他在提醒誰；既有對象關係見[口頭禪條目](../../memes/这下玩大了.md)，不把它機械塞給滅霸或任何受害者。這是寫法約束，不冒充 R15 評論裡已出現的句子。

## 變體與邊界

評論區本身就能完成一次「發文—起鬨—回嘴」，不一定非要剪成次日校園戲。能力意象也能參與傷感表達，例如響指改變宇宙卻改變不了心情；不能把評論自編文案署成原作者對白。

專屬校園流程另見[深夜 emo，次日被嘲笑](../校园宇宙/patterns/深夜emo次日被嘲笑.md)。
