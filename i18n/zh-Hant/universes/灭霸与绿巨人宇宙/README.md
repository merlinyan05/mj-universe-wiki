# 薩諾斯與綠巨人宇宙

- 常見場景：戀愛、健身、誤會、關係揭底、跨作品拼接
- 世界規則：記錄以兩人關係為核心的作者版本；各系列仍可能有不同進度與人物關係，不合并成同一連續劇情。
- 版本邊界：宇宙分類可以疊加，不是官方宇宙編號；具體作者版本分別記錄。

薩諾斯／浩克已有連續 CP 系列標題與合集資料。[R03](../../sources/R03.md) 健身片例也以浩克引起薩諾斯反應。[R11](../../sources/R11.md) 評論能續編後代，但不能把猜想升級為片內關係，更不能覆蓋其他作者版本。

## 人物與共用設定

人物統一查閱[人物檔案](../../characters/README.md)，這裡不另建人物副本。家長姓名、口頭禪等共用設定可以跨宇宙引用；身份變化與客串在人物檔案中註明版本。

## 故事模式與待補充

早期材料主要支持 CP 系列、目擊和借錢等標題線索；[R76](../../sources/R76.md) 現已補瘋狂淵淵第 2—4 集的伴侶與家庭日常、卡魔拉女兒稱謂，未據此還原全部集數或統一血緣機制。詳見[兩人關係條目](../../relationships/灭霸与浩克.md)。歡迎補充告白、誤會或關係曝光的實際片例；不憑標題補寫劇情。

## 相鄰整活版本

[R25](../../sources/R25.md) 的身體雙關與蟻人評論屬於另一條可觀察線索；沒有足夠證據把它合并進某位作者的 CP 連載。共用角色不代表單集關係、地點和後果全部相同。

## 作者家庭線與其他偏愛版本

[卡魔拉](../../characters/卡魔拉.md)在 R76 連載中被稱作女兒，家庭身份回寫人物與關係檔案，不按宇宙複製人物。[R82](../../sources/R82.md) 店主薩諾斯免費送浩克蛋糕、[R83](../../sources/R83.md) 手繪成年後續各屬其他作者，分別記錄，不合成一條共用家庭史。
