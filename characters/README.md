## 外观参考

截至2026-11-10，21份人物档案中有13份提供外部参考入口；灭建国、MJ与胖蜘蛛侠、贾维斯、命运博士、尼克·弗瑞、洛基、超人、卡魔拉共8份的专属参考仍待补。上表可直达各人物的参考区，包括电影、游戏、漫画与同人版本的三视图、多视图、概念设计及服装资料；资料类型、具体版本和核对范围写在各档案中，不能将一般概念图统称为完整三视图。

这是一组外链索引，没有把第三方图片搬入仓库，也不是成套的 MJ 校园角色素材包。资料公开可查看不等于允许转载、商用或上传至生成模型，本仓库的 CC 许可不覆盖外链图片与第三方角色权利。新增入口按[外观参考贡献说明](../CONTRIBUTING.md#人物三视图与外观参考)填写，不按宇宙复制人物档案。
